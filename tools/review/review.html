影剑士线 · 影剑士

sw-000W-1刀剑力量34敏捷35韧性21智力20幸运22体质18
分线本体
影分身：召出 2 个影子分身复制攻击，挨打就消散。剑士第一个"不只一个人"的职业。
分线定位
双剑士方向下的"一人成军"。玩家看到的是一个剑士身边多出影子，越往后影子越多，最后全队都带影子。是剑士树里最偏输出的一条线。
核心规则
影子是独立单位，各自结算伤害，不做伤害乘区（A23）。影子挨打就消散，所以脆、靠数量。影子只复刻普攻，不复刻技能，防止 AOE 叠爆。全场影子总数设上限，管住性能和画面。
成长路径
第 3 转「影分身」：2 个跟随的影子。第 4 转决定影子怎么用：绕身成剑环，或者瞬移合击。专精的光环把影子借给队友（影随 / 残影）。英雄的号令一次性给全队影子，或者让全员瞬移围杀。五星：64 位英雄各自强化自己的号令（原「」拆散进各英雄）。
  • 影武士流：环刃影武士 → 千刃舞者 / 残影舞者 → 影幕·艾伦 / 孤刃·凯 / 残月·琳 / 千面·塞拉 → ★万刃 / ★无双 / ★天阵 / ★坠星
  • 刺客流：瞬影刺客 → 追魂刺客 / 幻身刺客 → 影杀·夜 / 追魂·刹那 / 鬼步·狄恩 / 分光·维克 → ★无影 / ★瞬狱 / ★斩首 / ★噬天
影武士流
影子贴身高速旋转，本体钻进怪群清场。关键词：贴身、持续、范围。推荐路线是 进取「影随」+ 授「影卫号令」，终点是"人海"。AI 接敌距离要单独调近。
刺客流
影子瞬移到标记目标身后合击，打完与一个影子换位。关键词：标记、瞬移、爆发、单体。这是剑士树唯一的精英点杀线。推荐路线是 守护「残影」+ 令「群影猎杀」。索敌优先级定为：精英 > 远程 > 最近。
团队角色
前期团队贡献主要是诱饵：影子会吸走仇恨。专精以后把影子分给队友，团队化程度一路上升，是全树最完整的团队化曲线。
体验目标
高光时刻有两个：画面从 1 人变成 3 人，再到全队人数翻倍；刺客流里本体突然出现在精英身后。
边界
和盾阵兵（也是分身）的区别：影子复制攻击，又脆又快；盾兵是阻挡用的地形，肉，不出手。和其他树的召唤类职业的区别：影子不独立行动，永远围着本体或目标转。
风险与自查
"复制攻击"如果按伤害倍率实现会违反 A23（技能不能新增乘区）——必须按"额外单位、各自结算"实现。

分线本体
巨人化：变身巨人数秒，生命与击退大增，移速攻速降低，免疫击退。完全按你的示例。
分线定位
重剑士方向下的变身系：变成巨人，慢，但一下打一片，是前排压迫感最强的一条线。
核心规则
五星以前巨人形态有时限。巨人化后体型、生命、击退大增，移速和攻速降低，并免疫击退。流场寻路里巨人算障碍物，队友要能绕开。BOSS 和重甲怪免疫抓取。
成长路径
第 3 转「巨人化」。第 4 转二选一：「撼地」（每一步都震地掀飞）或「擎天」（抓怪投掷）。专精光环：「巨力」（队友击退提高）或「坚岩」（队友免疫击退和硬直）。英雄号令：群巨号令，或者人肉炮弹。五星：64 位英雄各自强化自己的号令（原「」拆散进各英雄）。
  • 撼地流：撼地巨人 → 山崩巨人 / 磐石巨人 → 崩山·铁牛 / 断岳·格雷 / 磐石·哥顿 / 不动·托尔 → ★撼岳 / ★开天 / ★山岳 / ★镇狱
  • 擎天流：擎天巨人 → 流星巨人 / 城门巨人 → 流星·加隆 / 投石·马格 / 巨门·泰坦 / 擎岳·伍尔夫 → ★碎空 / ★陷城 / ★巨神 / ★天怒
撼地流
持续把怪推离队伍，替后排争取距离。注意两点：它和需要聚怪的 AOE 职业互相拆台，这是阵容取舍；号令「人肉炮弹」把人往怪群里扔，和撼地把怪往外推的方向相反。
擎天流
抓怪当炮弹，专门对付自爆怪和冲锋怪。"投掷"主题可以一直延伸到扔队友（人肉炮弹），是这个流派最纯的终点。
团队角色
前排一堵会走的墙，推挤控场。坚岩光环直接回答"推挤 / 迟滞"类挑战维度。
体验目标
体型变化一眼就能认出来；抓怪扔怪是全游戏独一份的手感。
边界
和堡垒兵（同为前排墙）的区别：巨人会走、会推，堡垒不动、靠造地形。和狂战士（同属重剑士方向）的区别：巨人靠体型控场，狂战士靠卖血爆发。
风险与自查
巨人体型会挡住队友寻路（流场寻路要把巨人当障碍）；体素资产需要整体缩放 + 慢速动画。
