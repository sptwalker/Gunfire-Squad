                驯鹰猎手线 · 驯鹰猎手

                ar-000W-1弓箭力量18敏捷36韧性10智力28幸运34体质24
                分线本体
                放鹰：一只猎鹰伙伴，扑你射中的敌人并打断它，空闲时飞到前方侦察、标出拐角后的敌人。全游戏唯一的"单只灵巧宠物"。
                分线定位
                游猎者方向下的宠物伙伴：猎手带一只猎鹰，鹰负责扑击、叼物、侦察，猎手负责远处输出。全游戏唯一的"单只灵巧宠物"。
                核心规则
                猎鹰是独立单位，各自结算伤害（A23）。鹰只扑你射中过的目标，先射后扑。打断对精英递减、对 BOSS 免疫。主鹰永远只有一只；号令借出的小鹰短时、半透明。
                成长路径
                第 3 转「放鹰」：扑击 + 侦察。第 4 转决定鹰的专长：扑倒要害，或者叼回补给。专精光环：「鹰视」（共享侦察）或「护翼」（啄退近身敌人）。英雄号令：群鹰号令或擒王。五星：每位英雄在自己的号令上单独强化。
                • 猛禽流：猛禽猎手 → 扑杀猎手 / 护巢猎手 → 扑杀·索尔薇 / 擒王·埃里克 / 利爪·英格丽 / 鹰吻·拉格纳 → ★长空 / ★天眼 / ★铁爪 / ★拔羽
                • 灵隼流：灵隼猎手 → 巡天猎手 / 衔环猎手 → 巡天·阿斯特丽 / 夺甲·比约恩 / 衔环·西格丽 / 归巢·莱夫 → ★百鸟 / ★衔甲 / ★衔归 / ★长鸣
                猛禽流
                猎鹰俯冲扑倒最危险的敌人。关键词：扑倒、打断、精英。推荐 进取「鹰视」+ 令「擒王」。
                灵隼流
                猎鹰叼回弹药血包。关键词：后勤、回收、续航。射手树唯一的续航来源。推荐 守护「护翼」+ 授「群鹰号令」。
                团队角色
                打断保护队友；侦察让全队提前看到拐角后的怪；叼衔是本树唯一的补给。
                体验目标
                猎人肩上一只鹰，鹰飞出去探路、扑怪、叼东西回来。
                边界
                和死灵法师（一群尸体）、蜂群技师（机械蜂群）的区别：只有一只，灵巧、会叼东西和侦察，不靠数量。和德鲁伊林间伙伴的区别：德鲁伊的伙伴是附属，驯鹰的鹰是整条线的主角。
                风险与自查
                鹰是独立单位，各自结算伤害（A23）。打断对精英递减、对 BOSS 免疫，否则鹰会锁死 BOSS。侦察依赖视线规则。

                                                套索是位移类控制：把敌人拽开或拉近，不定身。绊倒很短、会起身，靠频率。拉拽和绊倒对 BOSS 免疫，精英递减。钩爪需要可钩挂点，没有时退化为后跃。解锁投索类。
