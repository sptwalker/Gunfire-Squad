                军医线 · 军医

                md-000W-1药水 · 喷射力量14敏捷27韧性24智力32幸运20体质33
                分线本体
                战地急救：冲到最低血队友身边打一针，回血 + 套盾，自己同享护盾；倒地队友直接扶起。护盾与战地复活都只在这条线。解锁喷射武器（喷雾针剂）。
                分线定位
                随军医师方向下的战地急救：冲进火线打针、套盾、扶人。全游戏护盾和战地复活都只在这条线，是辅助树保命上限最高的一条。
                核心规则
                护盾贴在人身上、有血量、碎前一直存在，单人盾值有上限。复活每人单独冷却，扶起只带少量生命。急救时自己同享护盾，保证冲进火线不白给。旧版护盾、生命链接、战地复活并入本线。
                成长路径
                第 3 转「战地急救」。第 4 转二选一：「应急护盾」（厚盾，碎时震开）或「强心针」（隔空复活 + 药雾）。专精光环：「战意针剂」或「生命链」。英雄号令：全员急救，或战地医院。五星：每位英雄在自己的号令上单独强化。
                • 护盾流：护盾军医 → 盾刃医官 / 坚壁医官 → 战盾·布丽吉德 / 营盾·迪安 / 连心·艾尔米德 / 病房·米赫 → ★碎盾 / ★轮盾 / ★同心 / ★仁心
                • 回生流：回生军医 → 回光医官 / 续命医官 → 还魂·欧恩 / 不倒·菲奥娜 / 接力·康纳 / 担架·梅芙 → ★齐魂 / ★不屈 / ★传薪 / ★归营
                护盾流
                挡在伤害前面：厚盾、碎盾震开。关键词：护盾、反推、预防。推荐 守护「生命链」+ 授「全员急救」。
                回生流
                倒下也能拉回来：隔空强心针 + 药雾群疗震退。关键词：复活、翻盘、群疗。推荐 进取「战意针剂」+ 令「战地医院」。
                团队角色
                全队护盾、群体复活、平摊伤害，是辅助树团队保护最完整的一条。自保靠护盾同享与碎盾震开。
                体验目标
                军医冲到倒地队友身边一针扎下，队友弹起来，身上一层药膜。
                边界
                和力场工程师（屏障）的区别：军医的护盾贴在人身上跟着走，力场是地面固定区域、偏转投射物。和剑士幻影卫（全员虚化）的区别：幻影卫是无敌数秒，军医是有血量的盾 + 倒地后扶起。
                风险与自查
                "冲到身边"会把脆皮辅助带进怪群，护盾同享是自保补丁；冲刺距离上限要定。

                2. 远程复活的距离与冷却？倒地惩罚还剩多少？
                3. 战地医院和萨满图腾阵都是据点，是否接受两个据点号令并存？

                                                                                                                                                                                                                                                核心规则
                                                                                                                                                                                                                                                封印 = 目标技能数秒内不可用（含自爆怪的引爆）。驱散只清增益和护盾，不削血。首领只能被封小技能，大招免疫。净化清队友负面状态。
