                蜂群技师线 · 蜂群技师

                te-000W-1手枪力量14敏捷30韧性16智力42幸运26体质22
                分线本体
                无人机群：4 架小无人机跟随射击，被击落后重新组装。技师第一个召唤职业。
                分线定位
                遥控兵方向下的"小而多"。技师身边一群巴掌大的无人机，越往后越多，最后全队都接入蜂群网络。
                核心规则
                无人机是独立单位、各自结算，不做伤害乘区（A23）。被击落会自动重组，所以靠数量不靠耐久。全场无人机总数设硬上限。
                成长路径
                第 3 转「无人机群」：4 架跟随无人机。第 4 转二选一：散开巡猎自爆，或者附着在精英身上当信标。专精光环：蜂鸣协同 / 诱饵蜂。英雄号令：蜂群联网（分组跟队友）或蜂群围猎（围住一个精英）。五星：每位英雄在自己的号令上单独强化。
                • 猎杀流：猎杀蜂巢手 → 蜂暴操控师 / 群巢操控师 → 裂巢·蜂鸟 / 蜂暴·毒刺 / 巢卫·蜂后 / 蜂幕·纱幕 → ★群猎 / ★万蜂 / ★守巢 / ★蜂城
                • 标定流：标定蜂巢手 → 锁敌标定师 / 信标标定师 → 猎场·猎犬 / 斩标·准星 / 回声·蝉翼 / 蜂笼·铁笼 → ★猎王 / ★追猎 / ★鸣镝 / ★囚笼
                猎杀流
                无人机自己飞出去找怪自爆，偏清场。推荐 进取「蜂鸣协同」+ 授「蜂群联网」，杀得越多飞机越多。
                标定流
                无人机附着在精英身上标记易伤，是技师树唯一稳定的易伤来源。推荐 守护「诱饵蜂」+ 令「蜂群围猎」。
                团队角色
                前期诱饵分担火力，专精后把蜂群接到队友身上，授号令是"联网"而不是"发无人机"。
                体验目标
                满屏小飞虫；精英身上挂满闪红灯的信标。
                边界
                和影剑士（影子）区别：影子复刻本体攻击、围着本体转；无人机自己索敌、能打飞行怪、会重组。和驯鹰猎手区别：猎鹰是一只灵巧宠物，蜂群是一群不讲个性的机械。
                风险与自查
                全场无人机要设硬上限管性能；"数量多、小、跟随"要和影剑士影子（复刻本体攻击）拉开——无人机自己索敌、能打飞行怪。

                                                                                                                                                核心规则
                                                                                                                                                近距离锥形、持续，燃料打空要等回压。冰雾只减速不冻结（冻结归元素使）；酸只蚀甲不做药剂组合（那是炼金药剂师）。解锁喷射武器类。
