                元素使线 · 元素使

                mg-000W-1魔法力量16敏捷30韧性14智力44幸运26体质20
                分线本体
                三态轮转：法弹按 火→冰→雷 轮流挂元素，两种相遇触发融化 / 超导 / 蒸汽爆。旧版雷咒、霜咒、焚咒压缩成一条线。
                分线定位
                咒术师方向下的"元素化学"。元素只在这一条：火冰雷三态按顺序打出反应。旧版雷咒、霜咒、焚咒三条线压缩成这一条。
                核心规则
                法弹按 火→冰→雷 轮转挂元素，同一目标挂上两种就触发反应：融化（打掉护甲层）、超导（冻结）、蒸汽爆（原地炸开）。反应是额外判定与状态，不是伤害乘区（A23）。每个目标有反应冷却，防止刷屏。冻结只在这一条。
                成长路径
                第 3 转「三态轮转」：自动轮转。第 4 转决定反应怎么用：连锁传染，或者手动挑元素精打。专精光环把元素借给队友（元素引线）或者给近身怪挂冰（冰霜之息）。英雄号令：全队分元素互相触发，或者一次引爆全场元素。五星：每位英雄在自己的号令上单独强化。
                • 连锁流：连锁反应师 → 链爆术士 / 融霜术士 → 链火·伊格尼斯 / 天灾·普罗米 / 霜铠·格拉西娅 / 寒环·波瑞阿斯 → ★三相 / ★劫火 / ★冰铠 / ★凛环
                • 控相流：控相术士 → 相灭术士 / 凝相术士 → 三原·卡莉丝 / 熔核·赫斯提亚 / 相壁·弗尔古尔 / 静滞·阿斯特拉佩 → ★归元 / ★炉心 / ★蒸汽 / ★永寂
                连锁流
                反应会把元素溅到周围敌人，一圈一圈传下去。关键词：传染、清场。推荐 进取「元素引线」+ 授「三相授法」，终点是全队都是反应源。
                控相流
                不再自动轮转，自选元素，目标身上的元素留得更久，对精英反复打同一种反应。关键词：精准、破甲、单体。推荐 令「万象归一」走熔核，这是法师树最强的精英点杀。
                团队角色
                前期只有自己打反应；专精后队友的攻击也能挂元素，号令时全队互相配合打反应，团队化曲线完整。
                体验目标
                同一个目标上元素图标一闪一闪，第二种元素打上去时"砰"一下反应，读得懂也有反馈。
                边界
                和技师喷射兵的区别：喷射兵冰雾只减速不冻结，喷火是锥形持续灼烧，没有元素组合；冻结和反应只在元素使。和剑士附魔盾卫（若保留）的区别：附魔只给武器挂单一元素，不做反应。
                风险与自查
                自动轮转时反应频率取决于攻速，攻速叠高后反应刷屏，需要目标级反应冷却。

                3. 剑士附魔盾卫是否把元素整体让给这一条？

                                                分线本体
                                                骤雨：全场暴雨，雨势逐渐变大，敌人越来越慢、远程视野变短。
                                                分线定位
                                                咒术师方向下的"改天气"。不是一发一发的区域法术，而是一场覆盖全场、慢慢变化的天气，持续时间以十秒计。
                                                核心规则
                                                天气覆盖全场，强度随时间慢慢上升：暴雨减速、遮蔽视野；狂风有风向，推敌、加射程；雷云每隔一会儿劈最高的目标。天气不挂元素、不冻结，和元素使分开。同时只能有一种天气。
                                                成长路径
                                                第 3 转「骤雨」：全场暴雨。第 4 转把雨转成狂风（推怪、加射程）或积成雷云（定时劈精英）。专精光环：顺风（队友射程、移速）或雨帘（降低远程命中）。英雄号令：每人头顶一片天气，或者小队变成风暴眼。五星：每位英雄在自己的号令上单独强化。

                                                御风流
                                                狂风有方向，逆风的敌人被推回，顺风的队友射得更远。关键词：方向、推挤、射程。风向默认跟随队长朝向。
                                                雷云流
                                                雷云每隔一会儿劈雨中最高的敌人（精英、大体型），慢而准。关键词：定时、精英、持续。是风暴术士唯一的单体答案。
                                                团队角色
                                                天气是全场效果，天然惠及全队；顺风光环直接给远程队友加射程，是法师树对射手最友好的一条。

                                                一局里天色从晴变雨、风越刮越大、云越积越厚，整个战场的"氛围"在变。
                                                边界
                                                和元素使的区别：天候不挂元素、不做反应、不冻结，雷云的落雷是独立判定。和炮击观测员的区别：炮击是标记一点、延迟后爆炸；雷云是全场持续、自动挑最高的目标，单次伤害小。

                                                                                地脉术士线 · 地脉术士

                                                                                mg-010W-1魔法力量16敏捷14韧性14智力40幸运26体质40
                                                                                分线本体
                                                                                地脉共鸣：按施法处地形变效果——沙地流沙、水面通电、废墟落石。
                                                                                分线定位
                                                                                法则师方向下的"借地形打架"。同一个技能，按施法处的地形变成不同效果，让场景地形第一次成为职业的一部分。
                                                                                核心规则
                                                                                三种基础地形：沙地 → 流沙陷住、水面 → 通电麻痹、废墟 → 落石砸下。没有对应地形时效果最弱。只改地面材质，不造墙、不改寻路（墙是剑士堡垒兵的）。地形改动有总面积上限。
                                                                                成长路径
                                                                                第 3 转「地脉共鸣」：看地形施法。第 4 转二选一：自己改地面再施法（塑地），或者在节点上让整片连通地形一起发作（连脉）。专精光环：地利（队友按地形获得加成）或厚土（队友脚下硬地、减伤）。英雄号令：全队落点都触发地形，或者全场翻成一种地形。五星：每位英雄在自己的号令上单独强化。
                                                                                • 塑地流：塑地术士 → 沙海术士 / 岩甲术士 → 行地·特拉 / 桑田·奥瑞亚 / 磐基·佩特拉 / 沙城·西布莉 → ★行岳 / ★沧海 / ★磐石 / ★沙海
                                                                                • 连脉流：连脉术士 → 潮脉术士 / 磐脉术士 → 连脉·安泰俄斯 / 震岳·法乌努斯 / 地母·德墨忒尔 / 泽国·席尔瓦 → ★地心 / ★崩岳 / ★丰壤 / ★汪洋
                                                                                塑地流
                                                                                先把一小片地面改成沙、水或碎石，再借它施法。关键词：主动、自由、灵活。不依赖地图，是这条线的保底流派。
                                                                                连脉流

                                                                                                                                                分线定位
                                                                                                                                                奇术师方向下的"骗"。假目标、让敌人互殴、隐身都在这一条，幻象全游戏只在这里。
                                                                                                                                                核心规则
                                                                                                                                                幻象不造成伤害，只吸引敌人攻击，挨一下就消散。惑心让敌人短时间把同伴认成我方，互殴伤害按敌人自身攻击结算，不是我方乘区。隐身是这条线的主线之一，其他分线不做隐身主线。
                                                                                                                                                成长路径
                                                                                                                                                第 3 转「镜像」：2 个自己的幻象。第 4 转二选一：让敌人认错人（惑心），或者真身藏进幻象里背刺（隐匿）。专精光环：破绽（敌人追幻象时露出破绽）或替身幻影（替队友挨一下）。英雄号令：每名队友一个幻象，或者全场敌人互殴。五星：每位英雄在自己的号令上单独强化。

                                                                                                                                                与幻象换位后隐身，第一下从背后出手并多判定一次。关键词：隐身、换位、背刺。是法师树唯一主动贴近敌人的流派。

                                                                                                                                                幻象分散火力是全队受益；破绽光环给队友弱点判定；号令把幻象分给每名队友。

                                                                                                                                                                                分线本体
                                                                                                                                                                                变羊术：一个敌人变羊数秒，无害乱跑，挨一下就打回原形。
                                                                                                                                                                                分线定位
                                                                                                                                                                                奇术师方向下的"把敌人变成小动物"。变羊、变鸡、变青蛙，变形期间无害，受到一次攻击就打回原形。不是自己变身。
                                                                                                                                                                                核心规则
                                                                                                                                                                                变形是最强的软控：完全无害，但一击即破，所以和全队的输出天然冲突——要等变回来再打，或者先打别的。精英不能被变羊，只能被缩形（数值变小、不会一击打回）。变形全游戏只在这一条。
                                                                                                                                                                                成长路径
                                                                                                                                                                                第 3 转「变羊术」：单体变羊。第 4 转二选一：一次变一群（群变），或者专门缩小精英（畸变）。专精光环：宰羊（打回原形的敌人愣住被多判定一次）或惊变（攻击队友的敌人几率变鸡）。英雄号令：全队攻击都能变羊，或者全场变羊。五星：每位英雄在自己的号令上单独强化。

                                                                                                                                                                                群变流
                                                                                                                                                                                扇形一次变一群，把敌潮的前排变成羊群。关键词：群控、无害、喘息。推荐 令「万物皆羊」。
                                                                                                                                                                                畸变流
                                                                                                                                                                                缩小精英：体型、攻击、护甲都变小，不会被一击打回。关键词：精英、削弱、破甲。是变形师的点杀答案。
                                                                                                                                                                                团队角色

                                                                                                                                                                                                                第 3 转「恶魔契约」：献血召恶魔。第 4 转二选一：喂更多自己的血让它变大（血契），或者让它吞敌人续命并继承精英特性（魂契）。专精光环：魔焰（队友打恶魔的目标额外灼烧）或恶魔威压（恶魔替队友拉仇恨）。英雄号令：全队魔化，或者恶魔升格魔王。五星：每位英雄在自己的号令上单独强化。

                                                                                                                                                                                                                                                核心规则
                                                                                                                                                                                                                                                复苏需要现场有尸体，前期尸体少时弱，打得越久越强。仆从是弱小的独立单位，各自结算伤害，过一段时间再次倒下。每具尸体只能复苏一次（防止尸爆循环）。全场仆从有上限。

                                                                                                                                                                                                                                                第 3 转「亡者复苏」：唤起附近尸体。第 4 转二选一：唤起更多、倒下还能再爬起（尸潮），或者让仆从扑进敌群自爆（尸爆）。专精光环：亡者号角（光环内倒下的敌人当场爬起）或亡卫（仆从替队友挡刀）。英雄号令：每名队友的击杀都复苏，或者全场尸体一起唤起成亡者大军。五星：每位英雄在自己的号令上单独强化。
