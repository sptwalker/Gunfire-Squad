#1. 这一轮到底改了什么，为什么

上一轮最大的空缺：技能与僵尸的关键机制只写在 note 文案里。 "无视 40% 目标护甲"、"冻结 3 秒"、"召唤 2 只傀儡"——这些是散文。 后果是"这套阵容能不能破解这个挑战"这类问题无法计算，只能靠嘴说。

这一轮的改动只有一件事：把机制变成字段。

上一轮（文案） 这一轮（字段）
"无视 40% 目标护甲" piercePct: 0.4
"冻结 3 秒" freezeDuration: 3
"召唤 2 只傀儡" summons: 2
"全队对其伤害 +35%" vulnPct: 0.35
"投掷 3 枚手雷" hitsPerCast: 3
"链式激光额外跳 5 目标" chainTargets: 6
"令目标减速" slowPct: 0.4

Skill 现在有 15 个机械字段（见 characters.ts 的 Skill 接口）。 配平主乘区仍然只有三个：mul / duration / cooldown—— skillAvgMul() 只读这三个，其余字段一律不改变技能的等效 DPS。

那它们改的是什么？改的是这个技能能回答哪个维度。

举一个例子说明这个区分有多必要：

薇拉的 vulnPct: 0.35（标记目标，全队增伤）和萨满的 atkMul: 0.3（光环全队加攻） 在配平上是等价的——都是约 1.3 倍的队伍伤害乘区。 但前者需要集火窗口、后者是常驻光环。 所以一个回答【围猎】（BOSS 与小怪同时压上时要能分火集火）， 一个回答【开阔】（没有掩体、持续接战时要能一直打）。

同等的数值，不同的形状。 这就是"维度"和"数值"的分界线， 也是同样两个角色在不同关卡里价值完全不同的原因。

#2. 答案标签：能力的形状，不是强度

AnswerTag 有 15 个标签，定义在 scenes.ts（维度知识），赋值在 characters.ts（角色知识）。 词表放 scenes.ts 是为了保持"scenes.ts 不引用任何角色数据"这条设计顺序。

标签 含义 回答的维度
aoeClear 范围清场：一次攻击覆盖多个目标 潮涌
singleTarget 单体点杀：不制造额外目标 分裂 · 精英护盾
sustainedDps 持续输出：不需要窗口，一直在打 开阔 · 围猎 · 潮涌
burst 爆发窗口：短时间把伤害集中砸出去 围猎 · 精英护盾 · 突进 · 分裂
pierce 直线穿透：无视部分护甲，且吃站位 重甲 · 卡口
explosive 爆炸灼烧：高额定值伤害，不吃护甲减免 重甲 · 卡口 · 潮涌
armorShred 破甲腐蚀：把目标护甲降下来给全队用 重甲 · 精英护盾 · 围猎
control 控制减速：限制移动 突进 · 自爆 · 分裂
taunt 堵口嘲讽：把敌人固定在一点 卡口 · 围猎
mitigate 减伤护盾：降低全队承伤 突进 · 毒区 · 远程压制
sustain 续航治疗 毒区 · 迟滞
ranged 远程射程：在威胁范围外解决战斗 远程压制 · 自爆 · 迟滞 · 毒区
mobility 机动突进：走位成本对你更低 迟滞 · 毒区 · 远程压制 · 开阔 · 自爆
summon 召唤物：用编制外的单位分摊 突进 · 远程压制 · 围猎 · 卡口 · 开阔
debuff 标记易伤：为全队制造集火窗口 围猎 · 精英护盾

为什么不直接让角色写 answers: DimensionId[]。 那样"两套阵容解同一个维度"这件事就不可见了。 aoeClear 和 explosive 都能回答潮涌，但前者怕分裂、后者怕贴身； pierce 和 armorShred 都能回答重甲，但一个吃站位、一个吃集火。 用形状做标签，多解性才是数据，而不是文档里的一句声称。

注意几个标签刻意覆盖了看起来不相关的维度，这是设计意图：

  • ranged 一个人同时回答四件事：够得着远程、点得掉自爆、不用踩毒、不用走位。 所以一个狙击手在四种完全不同的关卡里都有位置——这是"通用性"的正确形态， 它不是"数值高所以哪都能上"，而是"这一个形状恰好对上四种压力"。
  • mobility 同理，覆盖五个维度。迟滞地形的答案不是"走得快"，是"走位对你便宜"， 所以躲自爆、离毒区、脱迟滞、在开阔地重新站位，都是同一个能力的四种用法。

#3. 12 名角色

#3.1 六属性：每人合计恰好 150

一级属性：六项，每人合计恰好 150 点（哨兵 §1 机械校验）。 旧版是四项合计 100，本轮把预算提到 150，并且把两个派生换了主人：

一级属性 提供 从谁手里接过来的
力量 STR 近战伤害乘区、近战击退力 —
敏捷 AGI 攻速、移速、远程击退力 暴击率
韧性 TGH 护甲、抗暴击、稳固 生命上限
智力 INT 能量、技能强度、冷却缩减 —
幸运 LUK 暴击率、高级道具掉落权重 从敏捷处接
体质 CON 生命上限 从韧性处接

两条迁移各自解决一个具体问题：

  • 敏捷不再影响暴击。 旧版里敏高＝攻速高＋暴击高，两个乘区叠在一条属性上， 于是"敏"是唯一值得堆的输出属性。拆开之后，攻速与暴击是两份要分别花出去的钱： 凯（敏 28 幸 32）是暴击流，杰特（敏 38 幸 36）是攻速流，两人不再是同一种人。
  • 韧性不再加生命，改为提供抗暴击与稳固。 韧性从"更肉"变成"更难被暴击、更难被推动"—— 它守的是控制对抗轴，不再是血条（见 §3.2）。

100 → 150 是重新参数化，不是加强。 每个角色的老四维都下调了， 差额按定位分给幸运与体质。代价是哨兵 §2 要守住一条硬闸门： 每个角色的 heroEffectiveDps 与 heroEhp 相对重配前的偏离 ≤10%。 做不到这条，三个 BOSS 的血量与整条 15 分钟曲线都要一起重跑。 实测最大偏离是艾拉的 +6.9%，闸门守住（哨兵 §2 第二张表，逐角色列出旧值/新值/Δ）。

  • 极值变干净了。 罗恩是"幸 4 / 体 54"，薇拉是"幸 38 / 体 15"—— 一个赌自己不会被打中，一个赌自己不会打偏。改成六项之后， 同一个定位里的两个角色能靠幸运与体质彻底分开，而在四属性时代 罗恩和格温的区别只有"力 28 对 30"这种看不出意思的差。

#4.1 稀有维度是真正的约束

上表里 定位 那一列才是有信息量的：

维度 定位数 说明
迟滞 4 只有机动力与治疗能答——全游戏最窄的维度
重甲 5 只有穿透/爆炸/削甲类，与"堆攻击力"完全隔离
开阔 4 需要持续输出或编制外单位
毒区 4 治疗、射程与机动
其余 9 个 5-6 覆盖宽松

迟滞是最窄的维度，而且它的 4 名回答者（罗恩、凯、薇拉、莉安）与毒区完全重合：

迟滞 = 毒区 = { 罗恩, 凯, 薇拉, 莉安 }

这意味着任何要打沼泽疫地或雪原冻土的阵容，都必须在这 4 人里选人—— 而这两个场景的维度构成不同（一个是迟滞+毒区+远程压制，一个是迟滞+围猎+精英护盾）， 却指望同一批角色。这是"阵容选择有后果"目前唯一真正站得住的实例， 同时也是它的上限：整个 13 维体系在【覆盖】这一层只收敛出这一条约束（见 §7.2）。

#4.2 控制抗性：约束在判定，不在覆盖

新维度的尺子不是"谁能答"，是同一种控制手段对不同僵尸的命中率差多少。 三张判定表由 npm run sim §11 输出，详见 08-关卡方案.html §7.4。这里只留结论：

目标 位移命中率（铁牛·大刀，全队最强击退 96.8） 冻结 4 秒实际 嘲讽命中
普通僵尸 0.75 4.00s 1.00
毒液僵尸 0.66 1.60s 1.00
跳跃僵尸 0.75 3.60s 0.40
护盾僵尸 霸体 2.60s 0.70

全员可答，但没有人能一个人答完。 队伍里只有冻结就过不了毒液， 只有嘲讽就过不了跳跃，只有击退就过不了霸体—— 所以这一维度真正的门槛是阵容里必须凑齐开不同门的手段。

control（减速）是唯一不受抗性影响的一格，它永远关不上。 这是刻意留的地板：任何一层控制都能被完全免疫的话，控制流整体作废。

#5. 专精树：技能点花在这里（B4/B5 修订）

#5.1 硬约束：专精只能改公式的输入，不能新增乘区

SpecEffect 是一个刻意设计过的联合类型，里面没有"新增伤害乘区"这个变体：

export type SpecEffect =
  | { kind: 'attr'; attr: keyof Primary; amount: number }
  | { kind: 'weaponTier'; amount: number }
  | { kind: 'skill'; field: 'cooldown' | 'duration' | 'mul' | 'healPerSec' | 'teamDefMul'; amount: number; mode: 'add' | 'mul' }
  | { kind: 'ai'; field: 'aggroRange' | 'leashRange' | 'engageDistanceMul' | 'retreatHpPct'; amount: number }
  | { kind: 'answer'; add: AnswerTag }
  | { kind: 'revive'; charges: number };

原因是一条已经付过代价的约束：core.computeDamage 与 sim.computeDamage 之间 有一个 324 用例、1e-6 容差的对账测试，前提是两者签名一致。 一旦专精能插乘区，core 就要多接一个参数，对账测试立刻失效。

这条约束由编译器执行，不是靠注释提醒。

#5.2 节点效果分五类，其中一类最重要

类型 作用 是否改变"这个角色能进哪些阵容"
attr 增减一级属性 ✗
weaponTier 解锁更高武器阶 ✗
skill 改技能参数 ✗
ai 改索敌/走位参数 ✗
answer 新增维度答案 ✓ 唯一一类

只有 answer 类节点改变阵容可行性。 这正是用户要的"build 小队不同维度战斗能力"—— 其余四类都是数值强化，只有这一类是能力拼图。

所以设计规则是：每个角色的专精顶层节点，原则上应该是 answer 类。 下面是实际数据，以及它暴露的问题。

#5.3 12 棵专精树

每个角色 3 个节点，成本 1/2/3，按顺序解锁。顶层（cost 3）是决定性的那个。

11 / 12 个顶层节点是 answer 类，剩下 1 个是复活（莉安）。没有纯数值顶层了。

#5.4 四个新本事（用户裁决 C6-#3）

上一版这里记的是"4 个顶层节点只加数值"（薇拉 mul ×1.5、杰特 mul ×1.6、艾拉 cooldown −6、诺克斯 duration +10）。 用户给了方案：全部改成新本事。每个都挑一个该角色原本没有的答案标签——给已有的标签等于没给。

角色 新本事 形状 标签 新增维度
薇拉 贯日狙击 直线超远程（60 格）穿透一切目标 + 击退 pierce 重甲 · 卡口
杰特 天降火雨 半径 6 格、持续 8 秒的区域轰炸，灼烧不吃护甲 explosive 重甲 · 卡口
艾拉 永冻领域 半径 10 格，普通僵尸冻成冰雕、永久退出战斗 mitigate 突进 · 远程压制
诺克斯 亡者军团 唤起周围尸体为傀儡，≤12 具、30 秒、50% 血量 mitigate 突进 · 远程压制

四条边界，都是为了不让"新本事"变回"新数字"：

  1. 薇拉的击退走对撞判定（knockChance，击退力 vs 稳固）。霸体只免位移，所以打高防胖时穿透伤害照吃、人推不动—— 这让它是重甲的答案，不是控制抗性的答案。
  2. 艾拉的"永久"只对普通僵尸。冻结按 freezeRes 判定（毒液 0.6 大概率冻不住）， 精英与 BOSS 只冻 3 秒——否则一个技能就能跳过全部 BOSS 锚点。冰雕一击即碎，照常结算击杀与掉落。
  3. 诺克斯的军团需要尸体：开局与清场后没有料，精英与 BOSS 的尸体唤不起。它越打越强，但不能开局就用。
  4. 标签选的是"它实际在做什么"，不是名字像什么：艾拉的永冻本质是"冻住的敌人不再造成伤害"， 诺克斯的军团本质是"一堵替小队吃伤害的肉墙"——都是减伤（mitigate）。诺克斯原先考虑给 taunt， 但实测 0 个新维度（召唤已覆盖卡口 / 围猎），故改。

skillAvgMul 的变化：旧的数值节点让四人的技能平均倍率 ×1.02-1.29，答案节点不改倍率， 所以四人点满后的持续 DPS 回到裸技能水平——新本事换走的是数字，换来的是形状。BOSS 锚点不受影响。

#5.5 C2 落地：全游戏唯一的复活

决策 C2 明确"不做统一的队员复活机制"。所以没有任何通用复活： 队员阵亡就是阵亡，本局不再回来。

唯一例外是莉安的顶层节点「战地复活」（{ kind: 'revive', charges: 1 }）： 每局一次，把最近阵亡的队员以 50% 生命拉回战场。

为什么放在辅助位的专精顶层而不是做成通用机制： 通用复活会让"阵亡"这个状态失去意义——所有人都能回来，等于没有阵亡。 做成一个角色的一条专精，它就变成了阵容决策：你要不要为了这一条， 占掉一个位置、并且把 3 点专精全押在莉安身上？

#6. 两条局外线：技能点与军衔

局外成长在本轮拆成三条产出条件互不重叠的线：

线 货币 从哪来 给什么
深度线 技能点 新星级（每颗新星 1 点，每关每档三星封顶） 专精节点 · 高级技能
资历线 荣誉值 → 军衔 局内随机任务 更聪明的 AI · 低级技能增强 · 战术动作 · 高级技能资格
选项线 金钱 局内击杀累积，结算带出 武器 / 道具本身（买断、全队共享）

三者的产出条件不同，所以不存在"刷一个最优关卡同时喂满三条线"。 数据在 src/data/progression.ts，实测在哨兵 §12。

并且局内没有任何购买动作。 等级按秒表涨（run.ts 的 LEVEL_TIME： 90s→2 级，240s→3 级，450s→4 级，660s→5 级满级），武器阶随等级涨。 玩家在关卡里唯一要做的事是打——钱和荣誉都是带出去才生效的。

#6.1 技能点：星级（用户裁决 #4）

每个关卡的每档难度各自最多 3 颗星。第一次拿到某颗星给 1 点， 三星之后这一关不再产出技能点。

星 条件
★ 通关
★★ 通关，且最终全员存活（莉安战地复活拉回来的算活着）
★★★ ★★，且完成本局全部局内任务

三颗星各是一道看得见的门槛，不是分数线——玩家读得懂"差哪一颗、要怎么补"。 二星逼的是"阵容能不能扛住"，三星逼的是"扛住的同时还能分心做任务"，两条都指向换阵容。 上一版的"效率分"（清怪速度 × 生存）随之废弃：分数线要解释，门槛不用。

供给上限：82 关 × 3 星 × 3 档 = 738 点
全部需求：12 棵专精树 + 12 个高级技能 = 120 点     供给/需求 = 6.15

技能点线上从此没有"刷"：重打一关唯一的收益是补上没拿到的星， 而补星只能靠打得更好。供给是需求的 6 倍，所以不需要三星全收集也能点满—— 多出来的空间是给"换阵容去补星"留的，不是给"刷"留的。

同一批点既升技能等级，也点专精树（Profile.specPoints 本轮改名 skillPoints， 两套点合并成一套）。这样玩家不用在"点技能"和"点专精"之间做预算分配—— 它们本来就是同一件事的两面。

#6.2 军衔：12 级，效果只含 skill / ai / tactic

荣誉值来自局内随机任务（护送 / 守护 / 拾取三种，见 01-系统策划案 §11）， 结算时平均分给所有参战队员：3 个任务 × 12 + 通关奖励 20 = 56/局， ÷ 5 人 = 每人 +11.2/局。

不分 MVP、不全给队长，是这一条的题眼：换阵容不会让某个角色落后。 12 个角色一起长，玩家每换一套阵容都是拿一支成型的队伍去打， 而不是在重新养一个白板。

级 军衔 累计荣誉 本级效果
1 列兵 0 —（起点）
2 上等兵 60 ai.retreatHpPct +0.05
3 下士 150 cooldown ×0.92
4 中士 260 ai.aggroRange +2
5 上士 400 duration ×1.15 ← 同时是高级技能的门槛
6 准尉 580 mul ×1.12
7 少尉 820 ai.engageDistanceMul −0.1
8 中尉 1,150 cooldown ×0.88
9 上尉 1,600 mul ×1.15
10 少校 2,200 ai.aggroRange +3
11 中校 3,000 duration ×1.20
12 上校 4,000 mul ×1.18 cooldown ×0.90

军衔不直接加任何战斗属性，这一条由编译器执行：

type RankEffect = Exclude<SpecEffect, { kind: 'attr' }>

与"别给 SpecEffect 加 damageMul"是同一手法。12 条效果全部是 skill / ai， 哨兵 §12d 是运行时的第二道保险。军衔明确不能给： attr / answer / revive / weaponTier。

原因还是那句：它给的是新答案，不是新数字。 更聪明的索敌（打威胁更大的、更及时地躲范围伤害）改变的是队伍的行为， 不是同一套打法打得更疼。

#6.3 高级技能要两把钥匙

需求里有两句话："技能点解锁高级技能"（P5）与"军衔解锁高级技能"（P6）。 唯一能让两句同时为真的读法是两把钥匙都要：

军衔到 5 级（上士）→ 拿到资格
技能点花 4 点       → 买到手
军衔 已购买 高级技能
1 — 未解锁
1 ✓ 未解锁
4 ✓ 未解锁
5 — 未解锁
5 ✓ 解锁

只有一把钥匙时，另一句需求就会落空。 这也让军衔线有了一个具体的、能看见的目标：不是"攒到 400 点"，是 "攒到 400 点之后，我可以给我最缺的那个位置买一个新答案"。

#6.4 三条线的时间成本

满军衔（上校 4,000）      358 局 ≈ 90 小时
  └ 到上士（高级技能门槛）  36 局 ≈  9 小时
12 个高级技能（4 点 × 12） 24 局 ≈  6 小时
解锁全部商品（142,800）    14 局 ≈  4 小时

三条线的长度是刻意错开的：军衔 90h > 高级技能 6h > 商店 4h。 最短的是商店，所以玩家最先到手的是选项与技能，长期投入的是军衔。 顺序反过来的话，玩家会在没有选项的情况下被迫先做长期投入。

这中间有一条要盯的边界：军衔是唯一可能把"打不过就回去刷"这条路重新打开的系统。 它的 12 条效果全部落在 skill / ai 上，这是守住的唯一手段—— 一旦为了让后段更有吸引力而给它加一条 attr，整个设计前提就塌了。

#7. 多阵容的可验证性——诚实的结论

这是用户明确要求的一条："每种挑战，玩家不止有单一的阵容方案，而是可以有 非常多种不同的组合阵容方案。" 这一条不能只靠声称，所以哨兵做了机械枚举。

#7.1 哨兵 §10 做了什么

枚举全部 C(12,5) = 792 套阵容，对每一关数"有多少套阵容能覆盖该关的全部活跃维度"。

阵容总数                                792
能覆盖全部 13 个维度的阵容              693 套（占 87.5%）
全 82 关里门槛最高的一关                736 套可行（占 92.9%）

#7.2 这个数字证明的事情比它听起来弱得多

覆盖门槛几乎不筛人。 最紧的一关也放行 92.9% 的阵容。 原因是结构性的：5 名队员、每人平均能回答 8.4 个维度，并集自然铺满全集。

所以"能不能进"这件事基本是免费的。二分覆盖数不能证明"阵容选择有后果"。

而且 82 关里有 38 关并列同一个门槛（736 套）。按维度构成归并只有 7 组—— 门槛完全由「最稀有的那个维度」单方面决定：

含 sluggish  → 736 套，不管另外两个维度是什么
含 poison    → 736 套，同理
其余         → 760-771 套

换句话说：13 个维度里，只有 2 个（迟滞、毒区）在覆盖层面真正约束阵容—— 而且约束的是同一批人（§4.1）。 所以两条约束实际只有一条。 其余 10 个维度"答不答得出来"几乎不构成门槛。这是本轮设计的下限， 必须说清楚，而不是拿 792 这个数字当背书。

#7.3 真正该量的是什么，为什么现在量不了

决定阵容区分度的不是"能不能答"，是"答得好不好"—— 同一维度下不同答案的效率差。

具体地说：用穿透枪阵解潮涌，和用范围清场解潮涌，清怪速率差多少？ 如果差 5%，那两个答案其实是一个；如果差 40%，阵容选择才有后果。

要量这个，必须把维度折进刷怪与承伤模型——让"开阔"真的改变刷怪方位分布、 让"迟滞"真的改变走位时间、让"潮涌"真的改变同时接战数。 这需要 M2 参数化 run-sim.ts（当前有 10 处硬编码的 3 阶段假设）。

当前模拟器结构上做不到，所以本轮不声称阵容已经有多样性。 只声称一件事：维度没有死胡同——每个维度都有 ≥3 种答案形状、 ≥2 个不同定位可回答，不存在"没有任何角色能应付的维度"。这是可玩性下限。

#7.4 剩下三个能立刻做的方向

不在本轮范围，但记在这里避免遗忘：

  1. 加稀有维度：目前只有 2 个维度真正筛选阵容。把更多维度的答案面收窄 （比如让"开阔"也只有 3 个定位能答），阵容选择才会真正有后果。
  2. 把"答案数量"换成"答案效率"：给每个 AnswerTag 对每个维度的 效率系数，哨兵直接算加权值而不是布尔覆盖。这不需要动模拟器， 只需要一张 15×12 系数表——这是当前架构下最便宜的下一步。
  3. M2 原型：让维度真正影响刷怪与走位，用实测数据回填第 2 步的系数表。

#8. 未定项

  2. 专精点的获取曲线 已答（#4）：星级制，见 §6.1。

  5. 金钱买种类还是消耗品 已答（#1）：买的是非消耗品本身（武器 / 装备 / 法术 / 道具）， 一件可以同时装给多位会用这一类武器的角色（Hero.weaponClasses）。
  6. 军衔后段的吸引力 已答（#9）：后 6 级改为解锁战术动作 （构筑工事 / 布设地雷 / 埋设陷阱 / 架设堡垒 / 呼叫炮火），触发时 HUD 给文字提示（#10）。 战术动作不给维度答案，attr 的边界没有动。
  7. 同类武器之间的 DPS 跨度 已答：方案 B（同类 ≤×1.3）+ 新增步枪类。 原问题（留档）： 武器已按类别限制（刀剑 / 长柄 / 弓箭 / 短枪 / 狙击 / 爆炸 / 喷射 / 投掷 / 能量）， 角色只能换自己会用的类别。跨度从 ×3.80 收窄到 ×2.40，但没有消失（哨兵 §13a）： 艾拉冷冻器 → 喷火器 ×2.40、莉安手枪 → 弓箭 ×2.39、博姆手雷 → 火箭筒 ×2.03。 BOSS 血量按默认武器配平，所以这几组仍会让金钱买到数字。可选修法：
    • A. 同类内按默认武器归一化：换武器只换伤害类型 / 射程 / AOE 形状，总输出按默认武器折算。
    • B. 同类武器直接配平：把同类内的 DPS 差压到 ≤1.3（改武器数值，而不是改规则）。
    • C. 接受并重锚：BOSS 血量按"每人同类最优"重配。 落地（weapons.ts，闸门常量 SAME_CLASS_DPS_CAP = 1.3，哨兵 §13a 超标打 ✗）：
    • 手枪 65 → 88、冷冻器 45 → 62、喷火器 32 → 23、火箭筒 1100 → 680；冲锋枪不动。
    • 新增突击步枪（步枪类，穿刺 58 × 3.0/s，射程 30、穿透 40，售价 7,200）： 冲锋枪与狙击枪之间的中远距全自动。薇拉、杰特可用（杰特换步枪 ×1.08）。
    • 莉安不再会用弓箭：弓箭与短枪不同类，拉平同类管不到跨类，她换弓箭仍是 ×2.00，会击穿 BOSS 锚点。
    • 实测同类跨度：刀剑 ×1.11、短枪 ×1.28、爆炸 ×1.26、喷射 ×1.25；最大换武器增益罗恩 → 长枪 ×1.27。
    • 代价：短枪与喷射的默认武器被改了，艾拉 / 莉安 / 萨满的 DPS 基线重取（93 / 96 / 264 → 128 / 130 / 190）， BOSS 校准（±15%）仍全部达标。
