12 角色外观规则（备忘）

955 个职业形象全部由 proto/m0/tools/voxel.py 生成，配色来自 tools/palette.py。本页把散落在代码和 05 §2.4 里的外观规则集中记一份，以后加职业或改形象时照这里来。代码和本页不一致时以代码为准，并回头改本页。

1. 总则

  • 一个职业一个模型：vox_<职业 id>.glb，五星的 + 写成 _star。骨架、动作、手部挂点全树共用。
  • 俯视读图顺序：轮廓 → 主色 → 武器 → 细节。每一转至少加一个从俯视能看见的新轮廓件；只换色或只加花纹不算转职。
  • 不挡腿：髋部前方、腰带以下的格子一律删掉（recolor 删除 Hips 上 z<9、-4≤y≤0、-4≤x≤3 的格子）。下摆、法袍、披风只放在背后和两侧。
  • 955 个两两不同：出模时用「体素 + 左右手武器」做指纹，有重复就断言失败。
  • 地牌颜色和装备配色分开：近战深黄、远程浅蓝、辅助浅绿，只用在地牌上（index.html 的 TREE_COL），不跟着职业色谱改。

2. 配色（palette.py）

坐标是 t（转数，0 = 基础 … 6 = 英雄，7 = 五星）和 u（本转从左到右的位置，0–1，等于路径二进制取中点）。每个格子算出 6 个颜色：主色、辅色、裤色、装饰色、发光色、色相。

树主 / 辅根色相 → 左 / 右亮度（0…6 / 五星）五星彩度特别规则
剑士蓝 / 银白248 → 268 / 225.62 … .53 / .86.07全在蓝区，不用紫：飘带、光效、龙翼里的紫一律换成蓝
射手黑 / 紫325 → 310 / 345.32 … .24 / .26.16（主色 ×.25）主色近黑炭灰；紫只上领口、袖口、花纹、发光件；左肩到右腰一条棕皮带；装饰色比通用色阶暗一档（古铜 / 暗银 / 黑金）
法师红 / 橙30 → 12 / 62.62 … .59 / .70.15法袍前面开口
辅助绿 / 白150 → 180 / 122.70 … .71 / .90.08辅色无彩（亮度 .93 的白）
技术黄 / 青100 → 72 / 118.66 … .78 / .80.15辅色比主色暗 .08
  • 饱和度随转数涨：彩度 0…6 转为 .008 / .03 / .055 / .075 / .095 / .115 / .135，低转是灰、灰调、暗色调。
  • 色相随转数散开：散开系数 0 / 0 / .2 / .4 / .6 / .8 / 1 / 1。基础和 1 转不散；靠左的偏向 hl，靠右的偏向 hr，亮度左暗右亮（±.05）。
  • 装饰色阶：0–1 转铜，2–3 转银，4–5 转金，英雄亮金，五星每人一个亮彩色相（oklch .84 / .17 / 360u+20）。
  • 五星主色不能像皮肤：白金套的「白」会被换成五星主色。亮度太高、彩度太低时会和肤色混在一起。法师（.70 / .15）和技术（.80 / .15）都因此调过。新树要先截图检查五星这一排。
  • 树间断言：剑士色相在 222–270 之间；射手在 305–348 之间，并且和剑士同格主色不同；射手 64 个英雄的发光色至少 40 种。

  • 招牌件函数里 n = t − 3 是「这一转比 3 转多几阶」，件数、长度、圈数都随 n 增长，英雄时 n = 3。按下标取的位置表要至少有 n 的最大值 + 增量那么长（写辅助 / 技术时这里越界过一次）。
  • 发光件从 3 转开始出现，颜色用家族发光色；手写链的 0–2 转不发光（树色件本身可以是浅亮色）。
  • 手写链用占位色 MG_M / MG_S 表示「本格主色 / 辅色」，recolor 统一换成色谱色。所以链上的颜色不用手调，改色谱即可。

4. 路径 → 家族 / 流派 / 光环 / 号令

职业 id 的路径是一串 0/1：d = p0·2 + p1 是方向（选脸型模板），f = d·2 + p2 是家族（8 个），v, a, o = p3, p4, p5。

位含义外观上的体现
v（4 转起）流派招牌件分成两种形态，例如辅助「战地急救」v0 光盾 / v1 除颤器。招牌件函数用 if t >= 4 and v == … 分支
a（5 转起）光环方向aura_trim：进取 = 肩线外放、尖、金；守护 = 内收、圆、银（挂在胸骨上，不跟手臂甩）。5 转的辅色在守护时换成银；五星守护的金边换银
o（英雄起）号令order_mark：授 = 背旗，令 = 头后令羽；h >> 1 换形状（方旗 / 燕尾旗 / 三角长旗 / 双杆旗；冠羽 / V 字双翎 / 扇形羽冠 / 后垂长翎）。颜色是本人专属色 oklch(.80, .16, (45h + 23f) mod 360)

5. 英雄与五星

  • 人物行（person(f, h, heavy, salt)）：英雄号 h = v·4 + a·2 + o。肤色、发色、发型、瞳色、体型都由公式错开，同家族 8 人瞳色两两不同（瞳色下标 f + 3h mod 8）。「重」家族（每树 heavy 指定）用短发 / 光头 / 头盔、多为壮硕、偶有胡子；其余用长发 / 马尾等、偏修长。各树用不同 salt 错开（剑士 0、射手 3、法师 5、辅助 7、技术 9），五棵树的英雄不会撞脸。
  • 英雄套：外套用家族的 coat 色，树色件上到领口和铠边；招牌件用 t = 6 的形态；加光环肩线和号令件。
  • 五星套：同一个人（人物行沿用英雄），白金整套 + 本家族招牌件的英雄形态（换成白金）+ 光轮或冠冕。所以五星的头后、背后件始终不比英雄小。家族 0 / 1 / 4 / 5 用光轮，2 / 3 / 6 / 7 用冠冕；守护多一圈内环或一排短齿。号令：授 = 肩侧两颗浮游光球，令 = 短披风。
  • 编号：五星在展示页写 7.x，英雄写 6.x。职业圆盘（展示页「职业 955」）的地牌在前面加树字母：S 剑士、M 法师、A 射手、H 辅助、T 技术，例如「S 3.5」；转.序号和形象页一致。圆盘上站的就是这 955 个形象模型。

7. 武器与攻击动作

  • 形象专用武器在 LOOK_WPN 里，出模时一起导出为 vox_<武器>.glb；共用武器（剑、枪、喷火器等 11 把）直接复用样板角色的模型。
  • 武器随转数升级，同一家族用同一类武器：3–4 转普通款，5 转起加大或加左手副武器，五星换白金款（*_star）。
  • 攻击动作按右手武器名选（index.html 的 lgrip）：
    • rifle：bow、amr、sniper、rail、gl、spray
    • onehand（attack_pistol）：revolver、wand、orb、tome、remote、detonator、emitter、injector
    • throw：lasso、hook、boom、flask、card
    • 其余走近战挥击（剑、斧、枪、法杖、镰刀、扳手、钻、树枝、图腾、琴……）
    新武器起名时要让它落进正确的那一类。

8. 校验与出模流程

  1. 改 palette.py 后跑 python palette.py，重新生成 palette.html；文件里的断言要全过。
  2. 出一棵树：blender -b --factory-startup -P voxel.py -- ../assets/src/Xbot.glb ../assets/build looks <sw|ar|mg|md|te>。每次都对全部 955 个做唯一性指纹，并重新导出全部形象武器。
  3. 用 gltf-transform meshopt 把 build/ 下的结果压缩到 assets/。
  4. 在 proto/m0/index.html 的形象页按转数截图检查，快捷键：6 剑士、7 射手、8 法师、9 辅助、0 技术（英雄页里 0 仍是「各拿自己的武器」）。重点看：五星主色和皮肤是否分得开，同分线两个流派能否一眼分开，背后件是否挡住脸。
  5. 文档里的三角面和体积从构建日志（LOOK_OK … tris）和 du 导出，不手填（数字见 05 §2.4）。
