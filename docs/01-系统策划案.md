# 01 系统策划案

> 核心玩法循环、战斗规则、AI 行为、经济、任务、关卡。
> 所有数值的**真源**在 `src/data/*.ts`，本文与代码共用同一份数据，不重复维护。

---

## 1. 一句话定位

**俯视 3D 小队生存射击。** 玩家只控制 5 人小队的队长走位，
其余 4 人自动跟随、自动索敌、自动开火、自动放技能；
目标是在**世界地图的 6 个场景 / 82 个子关卡**里抗住 3 波不断涌来的僵尸、
打掉 3 个 BOSS、并**尽量让每个队员都活到最后**。

设计上最反直觉的一条：**玩家不负责输出。**
输出是队员 AI 的事，玩家负责的是"把队伍带到正确的位置"。
所以本作的技巧不在准星，在于**读战场**——判断哪一侧压力最大、什么时候该撤、什么时候该贴脸。

第二条同样反直觉：**卡住玩家的不能是数值，只能是阵容。**
每个场景、每个子关卡提出一种**挑战维度**（压力来源），
玩家的长期成长是"解锁新关卡 → 撞上新维度 → 现有阵容解不掉 → 重组阵容"。
武器没有局外养成（C3），所以卡住的时候没有数值可以刷——**只能换人**。
详见 `08-关卡方案.md` 与 `09-角色与成长.md`。

## 2. 核心玩法循环

本节的两个循环（单局 / 秒级）**未改动**，本文档描述的就是它们。
新增的是外面两层：**元循环**从"解锁一个角色"扩成了"一张地图"。

```
长期循环（新）
  世界地图 → 6 个场景 → 每场景 13-15 个子关卡（合计 82 关）
      ↓ 每个子关卡 = 一次 15 分钟 run（下图的单局循环）
  撞上新的挑战维度 → 现有阵容解不掉 → 解锁 / 强化角色 → 重组阵容 → 通关

单局循环（15 分钟，未改动）
  ┌──────────────────────────────────────────────────────┐
  │  阶段 1 [0:00-5:00] 接触   → BOSS 腐化重装兵  [5:00]  │
  │  阶段 2 [5:00-10:00] 压制  → BOSS 毒母·薇丝   [10:00] │
  │  阶段 3 [10:00-15:00] 狂潮 → BOSS 尸潮之主·卡俄斯[15:00]│
  └──────────────────────────────────────────────────────┘
  （同一个关卡有普通 / 困难 / 噩梦三档，三档改的是**构成**不是数值——C4）

  秒级循环（玩家视角，未改动）
    观察 → 判断压力方向 → 移动队长 → 队员自动跟随交火
      → 拾取增益 / 顺手完成任务 → 积分升级 / 金钱升武器 → 重复

  局外循环（修订：B4/B5）
    结算 → 解锁新角色 / 新武器种类 / 新关卡
         → 积累专精点 → 点开专精节点（唯一的局外强化）
         → 换阵容重打
```

**为什么循环成立**：玩家每 15 秒就要重新判断一次"站在哪里"，
因为僵尸从四面八方来、队员有牵引范围、地形有阻挡。
这是持续的小决策流，不是一次性的战术选择。

**为什么长期循环成立**：难度增长主要来自**维度构成**而不是威胁预算
（同场景内预算只涨 ×2.05，维度却从 1 个变 3 个）。
所以"打不过"的体感是"我缺一种能力"，不是"我伤害不够"——
而唯一能补上这种能力的方式是换人。

## 3. 小队控制

### 3.1 控制方式

| 操作 | 键位 | 说明 |
|---|---|---|
| 移动队长 | WASD | 唯一的高频操作 |
| 鼠标视角 | 鼠标 | 俯视相机旋转 / 缩放 |
| 切换队长 | Tab / 1-5 | **核心战术操作**——把控制权交给谁，等于决定队伍往哪走 |
| 集火 | 数字键 / 点击 | 唯一的战术指令，指定全队攻击目标 |
| 拾取 | 自动 | 走到增益道具上即拾取，不需要按键 |

### 3.2 编队与牵引（关键机制）

```
软牵引范围 12 格
  └─ 队员超出 → 脱战回位，回位期间不攻击不索敌
     这是"惩罚玩家乱跑"的机制：把队长拉太远，等于主动废掉 4 个队员的输出

硬脱离范围 20 格
  └─ 队员超出 → 强制传送归队
     这是"防卡死"的兜底：防僵尸潮把队员推挤到地形里，导致队伍残缺
```

两个范围的距离差（12 vs 20）是**刻意的缓冲区**：玩家有 8 格的容错空间反悔。
若两值相等，超出一格就被传送，手感会很硬。

### 3.3 队长切换为什么是核心

队员的 `AIProfile` 决定它往哪站（近战前压、远程后撤）。
**换队长 = 换整支队的重心位置。**
例：被尸潮逼近时切成坦克当队长，整队重心前移，远程自然退到坦克身后；
需要撤退时切成狙击手当队长，整队重心后移，近战自动脱离接触。

这是一个**用站位代替指令**的设计——不增加按键，但提供战术表达。

## 4. 战斗规则

### 4.1 伤害公式（唯一真源：`src/data/damage.ts`）

```
最终伤害 = 基础伤害
         × 攻击乘区 (1 + 力量 × 0.02)
         × 等级乘区 (1 + 0.25 × (等级-1))
         × 技能乘区 (1 + 冷却占比 × (倍率-1))
         × 暴击期望 (1 + 暴击率 × (暴击伤害-1))
         × 护甲减免   [有效护甲/(有效护甲+100) 的反面]
         × 甲型克制   [7×4 矩阵]
```

其中：

```
有效护甲 = 目标护甲 × (1 - 穿透/(穿透+60))
```

**穿透削弱的是目标护甲，不是给自己加伤害。** 这一点很重要——
它让"穿透"成为一个独立的成长轴：面对 220 护甲的胖僵尸，穿透 60 相当于把它的护甲砍半，
收益远高于同等的攻击力提升。这让"带穿刺武器"成为一个有意义的战术选择。

### 4.2 甲型克制矩阵

无任何一格为 0——**避免出现"这把武器对这个敌人完全无效"的死局**。

| 伤害类型 | 无甲 | 轻甲 | 中甲 | 重甲 | 设计意图 |
|---|---|---|---|---|---|
| 冲击 | 1.00 | 1.10 | 1.00 | 0.85 | 通用，对重甲乏力 |
| 斩击 | 1.00 | **1.15** | 0.95 | 0.80 | 克轻甲，被重甲克 |
| 穿刺 | 1.00 | 1.00 | **1.10** | 1.05 | 穿透系，稳定 |
| 火焰 | 1.00 | 0.95 | 1.00 | **1.15** | 克重甲，被轻甲规避 |
| 冰霜 | 1.00 | 1.00 | 1.00 | 1.00 | 纯控制，无克制 |
| 爆炸 | 1.00 | 0.90 | 1.10 | **1.20** | 最强克制，但武器射速慢 |
| 毒 | 1.00 | 1.05 | 0.95 | 0.90 | 对轻甲优 |

### 4.3 AI 效率系数 0.75

纸面 DPS × 0.75 = 实战 DPS。
走位、切换目标、技能前摇、被击退都会损失输出。
**这个系数是配平的前提**，不是修正项——所有 BOSS 血量都建立在它之上。
若原型实测发现队员空转更多，这个值要下调，且必须重跑 BOSS 血量的反向校准。

### 4.4 换弹机制

远程武器用**弹匣 + 换弹**，不管理弹药总数。

理由：弹药总数是一种"资源管理"，但在自动战斗游戏里玩家管不到队员的弹药，
所以弹药总数只会变成一个"莫名其妙打不出子弹"的负反馈。
而换弹**时间**是可读的节奏起伏——玩家能看见、能预判、能在换弹窗口调整站位。

换弹惩罚在 DPS 计算里被摊掉：
```
换弹占比 = 弹匣容量 × 射击间隔 / (弹匣容量 × 射击间隔 + 换弹时间)
```
这让"大弹匣慢换弹"和"小弹匣快换弹"成为真正的取舍。

## 5. 队员 AI

### 5.1 三层结构

```
第一层：站位          engageDistanceMul × 武器射程 = 期望交战距离
                      近战 > 1.0 前压，远程 < 0.8 保持距离

第二层：索敌          aggroRange 内寻找目标，按 targetPriority 排序
                      closest（最近）/ weakest（最弱）/ strongest（最强）
                      leashRange 超出则脱战

第三层：开火与技能    能量满即放 / 条件触发（如自身血量 < 40% 放保命技）
                      血量低于 retreatHpPct 则后撤
```

### 5.2 差异化靠参数，不靠代码

12 个角色共用**同一套 AI 代码**，行为差异全部来自 `AIProfile` 的 5 个参数。
加一个新角色 = 加一行数据，不是加一个类。

示例对比：

| 角色 | 索敌 | 脱战 | 交战系数 | 优先级 | 后撤阈值 | 读起来的行为 |
|---|---|---|---|---|---|---|
| 铁壁·罗恩（坦） | 14 | 22 | 1.2 | 最近 | 永不 | 死战不退，顶在最前 |
| 鹰眼·薇拉（狙） | 40 | 55 | 0.8 | 最强 | 30% | 躲在最后，专打 BOSS |
| 疾风·凯（近战） | 18 | 26 | 1.1 | 最弱 | 25% | 贴脸收残血 |
| 圣手·莉安（辅） | 22 | 30 | 0.75 | 最弱 | 40% | 最怕死，最早撤 |

**薇拉的"优先打最强"是刻意的**：狙击手自动锁 BOSS。
这让玩家不需要手动点 BOSS，但需要理解"带薇拉 = 队伍重心会往后跑"。

### 5.2.1 控制/辅助的技能必须被建模，否则"带奶妈"是负收益

初版模拟器只算伤害，于是霜语·艾拉（93 DPS）和圣手·莉安（96 DPS）的价值**完全隐形**，
跑出来"均衡阵容 4/20 通关、无治疗阵容 20/20"——**带治疗反而更容易团灭**。

这是建模缺陷，不是设计结论。补上三个字段后（`src/data/characters.ts`）：

| 字段 | 含义 | 谁在用 |
|---|---|---|
| `teamDefMul` | 技能生效期间全队受伤乘以该系数 | 罗恩 0.5 / 博姆 0.6 / 艾拉 0 |
| `healPerSec` | 每秒回复全队，等于自身最大生命的比例 | 莉安 0.06 |

补上之后均衡阵容回到 20/20。**教训：任何"看起来弱"的角色，
先怀疑模拟器没建模，再怀疑数值不平衡。**

### 5.3 为什么不给玩家更多指令

核心体验是"单手控队长 + 读战场"。指令一多就变成 RTS，
而队员 AI 的可读性会被指令噪音淹没——玩家会去盯按钮，而不是盯战场。
**只保留"集火"一个**：它解决最痛的问题（"打错目标了"），且不增加持续操作负担。

## 6. 武器系统（13 种）

完整数值见 `02-数值表.md`。这里只讲设计取舍。

### 6.1 三条成长轴

| 轴 | 来源 | 作用 |
|---|---|---|
| 攻击力 | 力量属性 + 等级 | 通用基础 |
| 穿透 | 武器固有 + 武器阶 | **对高护甲目标的乘算收益** |
| 频率 | 敏捷属性 + 武器固有射速 | 单位时间输出次数 |

刻意让它们**互相不能替代**：狙击枪穿透高但频率极低（0.35/s），
冲锋枪频率极高但穿透低（10）。所以"哪把武器强"取决于**打什么敌人**，
而不是取决于一个全局的强弱排序。

### 6.2 武器阶

每把武器 3 阶，金钱购买：`+0 免费 / +1 花 700 / +2 花 1500`

```
阶加成：伤害 × (1 + 0.35 × 阶)    穿透 × (1 + 0.20 × 阶)
```

### 6.3 `hitsPerAttack` 为什么必须压低单发

`hitsPerAttack > 1` 的武器（大刀 3、手雷 6、喷火器 4、火箭筒 5、激光 3）
天然有 AOE 优势。所以它们的**单发伤害必须压低**，
否则近战群伤武器会直接碾压所有单体远程武器——大刀单发 190 vs 狙击枪 700，
但大刀一次打 3 个，实际总输出并不吃亏。

## 7. 僵尸系统（9 种）

### 7.1 设计原则：每种僵尸必须能用一个**行为动词**概括

否则它就只是一个换皮的血包。

| 僵尸 | 血 | 速 | 甲 | 行为动词 | 具体表现 | 贡献维度 |
|---|---|---|---|---|---|---|
| 普通 | 200 | 2.2 | 无 | **数量** | 构成战场底噪 | 潮涌 |
| 高速 | 120 | 5.0 | 无 | **冲刺** | 突进，惩罚站桩与长换弹 | 突进 · 开阔 |
| 高防胖 | 1400 | 1.2 | 重甲 | **阻挡** | 缓慢推挤，逼你处理它 | 重甲 · 卡口 |
| 毒液 | 350 | 2.0 | 轻甲 | **区域封锁** | 死亡留毒池，逼你放弃阵地 | 毒区 · 卡口 |
| 爆炸 | 400 | 2.6 | 中甲 | **逼迫走位** | 靠近自爆，范围 2.5 格 | 自爆 |
| 分裂 | 300 | 2.2 | 无 | **清场惩罚** | 死亡分裂 3 只小僵尸 | 分裂 |
| 跳跃 | 250 | 3.0 | 无 | **无视地形** | 跳过掩体，落地 AOE | 迟滞 · 开阔 |
| **护盾**（新） | 900 | 1.8 | 中甲 | **破防检查** | 正面护盾吸收固定伤害，破盾后 3 秒虚弱（受伤 +50%），**不吃控制** | 精英护盾 · 围猎 |
| **喷吐**（新） | 600 | 1.6 | 轻甲 | **远程压制** | 12 格外喷吐，不进入接触距离 | 远程压制 · 围猎 |

九种动词**互不重叠**，这样玩家在战场上一眼能读出战术含义。

**本轮新增的两只**（7 → 9）专门服务两个新维度，机制上是刻意反着来的：

- **护盾僵尸逼迫阵容准备"爆发窗口"这个能力**，而不是"更多的持续输出"——
  它的护盾吸收固定伤害，所以持续磨盾是纯浪费。
- **喷吐僵尸让"龟缩阵地"这个稳赢打法第一次付出代价**——
  在旧版里站着不动几乎总是最优解（见 `00-决策清单.md` D1：
  常规阶段贴身占比 0%），远程僵尸是从结构上修正它。

原有的 7 种各补一个 `dims` 字段声明自己贡献哪些维度（上表最后一列），**数值一个未改**。

### 7.2 两条反直觉的设计

**A. 胖僵尸的作用是"逼你处理"，不是"造成伤害"。**
1400 血（普通僵尸的 7 倍）但速度只有 1.2（普通的一半）。
它不会杀人，它只是堵住你的路、消耗你的输出时间。

**B. 分裂僵尸让 AOE 武器在这里变成负收益。**
打死 1 只分裂僵尸 → 变成 3 只小僵尸。
所以带大刀的队伍遇到分裂僵尸时，输出反而是倒扣的。
这迫使玩家理解"高 DPS 不等于最优解"，是阵容深度的主要来源之一。

### 7.3 阶段缩放

```
阶段血量倍率 [1.0, 1.7, 2.8]     阶段伤害倍率 [1.0, 1.5, 2.2]
```

血量倍率**必须略低于**小队输出成长（等级 1→5 是 ×2.0，武器 0→2 阶是 ×1.7，合计 ×3.4）。
这样玩家越打越轻松，压力集中在 BOSS 和刷新密度上。

初版用了 4.5——僵尸血量涨得比小队伤害快，阶段 3 场上堆到 80+ 只，前沿直接崩了。

> **注意这条缩放是"一次 run 之内"的。**
> 关卡之间的难度增长走的是另一条完全不同的机制——威胁预算与维度权重，
> 见 §8.6 与 `08-关卡方案.md` §4。两者不要混。

## 8. 关卡与刷怪

### 8.1 刷怪用"威胁预算"而不是"只数"

每只僵尸有 `threat` 成本（普通 1、胖 3、毒 1.8、爆炸 2）。
出怪速率以**威胁值/秒**表示，预算累积到够一只就刷一只。

**为什么不用只数**：用只数的话，调整出怪表（比如把普通换成胖僵尸）
会意外地大幅改变难度，因为胖僵尸的实际压力远大于普通僵尸。
用威胁值则"总压力"是可读、可控的常量。

### 8.2 三个阶段

| 阶段 | 时间 | 威胁速率 | 出怪构成 |
|---|---|---|---|
| 1 接触 | 0:00-5:00 | 3.0 → 4.0 | 普通 75 / 高速 25 |
| 2 压制 | 5:00-10:00 | 4.5 → 6.0 | + 毒液 / 分裂 / 爆炸 |
| 3 狂潮 | 10:00-15:00 | 4.2 → 4.8 | + 胖 / 跳跃（全类型） |

阶段 3 的威胁速率**低于**阶段 2 的终值——这不是笔误。
阶段 3 的出怪表里胖僵尸（threat 3）和跳跃僵尸占比更高，
同样的威胁值对应**更少的只数、更高的单体质量**。
表上看速率降了，实际压力是升的。

### 8.3 BOSS 战期间的处理：**不清场，但分阶段降刷怪**

| BOSS | 刷怪乘数 | 目标场上只数 |
|---|---|---|
| 腐化重装兵 | 0.18 | 3 |
| 毒母·薇丝 | 0.15 | 4.5 |
| 尸潮之主·卡俄斯 | **0.70** | 6 |

- 完全停止 → BOSS 战变成"打木桩 90 秒"
- 完全不停 → 阶段 3 的 BOSS 战会被杂兵淹没

**三个乘数差这么多，是必须差这么多。** 刷怪预算按**威胁值**计，
而阶段 2 的出怪表是数量型（普通/高速，威胁 1.0-1.2）、
阶段 3 是质量型（胖僵尸威胁 3.0）。同样预算下阶段 2 堆出的**身体**更多。

阶段 3 的乘数是阶段 2 的 4.7 倍，但只数只多 33%。
**倍数骗人，只数不骗人**——所以这张表要同时写乘数和只数，不能只写乘数。

初版三个阶段都用 0.35：关底战最低血量 96%，第二场 BOSS 只有 55%，
**难度峰跑到了第二场**。分阶段之后曲线才单调递增。

### 8.4 BOSS 登场：清杂兵，留特化型（重要设计规则）

**BOSS 登场时，移除场上用「数量」施压的僵尸（普通 / 高速 / 分裂小），
保留用「行为」施压的特化型（胖 / 毒液 / 爆炸 / 分裂 / 跳跃）。**

理由不是数值，是**读法**：
关底 BOSS 落地时如果场上还堆着 78 只杂兵，玩家阵亡后读到的是"我被围死了"，
而不是"我打不过 BOSS"。前者让人归因于随机性，后者让人想再打一次。

```
实测依据：
  清场前   15:22-15:29 的 7 秒内从满血到全灭，BOSS 还剩 68% 血
  全部清场 关底战最低血量 96.4% —— 但难度峰跑到了 10:40，关底成了过场
  清杂兵   关底战最低血量 84-88%，毒池/自爆/跳跃仍在逼玩家走位
```

**"全部清场"是一个看似正确、实际有害的过度修正。**
它确实守住了失败归因，但也把关底战抽成了纯 DPS 木桩。
真正的规则是"清掉肉墙，留下机制"——玩家不再被淹死，但仍然不能站着不动。

### 8.5 阶段 3 的"关底感"从哪来

关底 BOSS 的压迫感**不来自数值**（它的血量/护甲只比第二场高 10%-50%），
而来自三件事：

| 来源 | 具体 |
|---|---|
| 场上只数最高 | BOSS3 战 6 只 vs BOSS1 战 3 只 —— 玩家一眼能看出"更挤" |
| 特化型占比最高 | 阶段 3 出怪表含全部 9 种，毒池+自爆+跳跃+护盾+喷吐同时在场上 |
| 击杀窗口最紧 | 目标 60s，实测 53.5s，只剩 6.5s 余量 —— 三个 BOSS 里最紧 |

## 9. BOSS 规格

| BOSS | 时间 | 血 | 护甲 | 速度 | 攻击 | 目标击杀 | 实测击杀 |
|---|---|---|---|---|---|---|---|
| 腐化重装兵 | 5:00 | 48,500 | 200 | 2.0 | 260 | 30s | 27.9s |
| 毒母·薇丝 | 10:00 | 70,000 | 320 | 2.2 | 380 | 45s | 37.2s |
| 尸潮之主·卡俄斯 | 15:00 | 94,000 | 480 | 2.4 | 520 | 60s | **53.5s** |

**这张表必须同时列出"目标"和"实测"。** 只列目标的话，
没人知道校准到底成没成立；只列实测的话，没人知道余量是多少。
第一场和第二场余量偏大，是刻意的——那是教学曲线，第三场才是关底。

### 9.1 为什么 BOSS 血量是配平的**锚点**

配平链条是**反向**推导的：

```
定 BOSS 血量 → 反推小队必须在 N 秒内击杀 → 得出小队 DPS 目标
            → 反推单角色 DPS → 反推武器伤害 → 反推僵尸血量
```

所以 BOSS 血量是第一个该定的数，也是最后一个该动的数。
**修改规则：只在小队 DPS 公式或成长曲线变动后才重跑校准**（`balance-check.ts` §4b），
不要凭手感改。手填的第一版（6万/18万/48万）比实测需求高 3-6 倍，第 1 个 BOSS 就全灭。

### 9.2 超时机制

每场 BOSS 战上限 90 秒。超时 = 失败。
这不是惩罚玩家的机制，是**防止 BOSS 战拖成 5 分钟的耐力赛**——
90 秒足够看出"打不动"，继续拖只会让玩家难受。

### 9.3 胜利条件

**三个 BOSS 全部击杀**才算通关。不是"活到 15 分钟"。

这条曾经写错过：早期版本 `RUN_DURATION = 900` 被当成终点，
而关底 BOSS 恰好也在 900 秒登场，于是循环在 BOSS 落地那一帧就结束了——
**最后的决战根本没发生过，"通关"只等于"撑到 15 分钟"**。
现在循环跑到 `RUN_END = 900 + 90`，胜利条件是 `allBossesDead()`。

## 10. 经济与成长

### 10.1 双资源

| 资源 | 来源 | 用途 | 是否带出关卡 |
|---|---|---|---|
| 积分 | 击杀僵尸（1-6 分/只） | 升角色等级 | ❌ |
| 金钱 | 击杀僵尸（1-12 /只）、任务奖励 | 升武器阶 | ❌ |

实测一局产出：**约 3,200 积分 / 1,300 金钱**。

### 10.2 等级曲线

```
等级阈值 [0, 150, 400, 800, 1400]    每级 +8% 属性 + 25% 最终伤害
```

**注意伤害用的是独立乘区**（`levelDmgMul`），不是放大基础属性。

原因：`atkMul = 1 + 力量×0.02` 带一个 +1 基数。
若让等级去缩放力量，34→45 只会让乘区从 1.68 到 1.90（+13%），
完全跟不上关卡缩放。拆成独立乘区后，"升一级 +25%"是玩家看得见、算得清的。

### 10.3 金钱曲线

```
武器阶价格 [300, 700, 1500]      实测约在第 8-11 分钟全部升满
```

## 11. 任务 NPC

三种任务类型，**全部可在战斗中顺手完成，不要求原地站桩**：

| 类型 | 说明 | 为什么可行 |
|---|---|---|
| 护送至地点 | 把 NPC 送到地图某点 | 玩家本来就在移动 |
| 守护目标 | 保护一个点位 N 秒 | 玩家本来就要清怪 |
| 拾取并带回 | 捡到物品再送回 | 只是多跑一趟 |

**设计约束：不设计"原地不动 N 秒"型任务。**
本作的核心操作是移动，站桩型任务会直接和核心循环对撞。

## 13. 地图与地形

**本节按 C5 整段重写。** 旧版是"6 张地图、地形不同、机制微调"；
新版是**"6 个场景，各自的挑战签名不同"**——地形从"地图设定"降级为
**表达挑战维度的手段之一**（详见 `00-决策清单.md` C5 与 `08-关卡方案.md` §3）。

### 13.1 结构

```
世界地图 → 6 个场景 → 每场景 13-15 个子关卡（合计 82 关）
                        ↓ 每个子关卡 = 一次 15 分钟 run
                     三档难度（普通 / 困难 / 噩梦）
```

一个子关卡不是"一块地形"，是**一组维度权重 + 一套刷怪表 + 一个地形修正**。
地形修正、刷怪表、BOSS 分派全部由 `src/data/scenes.ts` 的 `expandScene()` 推导，
**不存在"手写 82 张地图配置"这件事**。

### 13.2 六个场景

| 场景 | 签名维度 | 地形修正 |
|---|---|---|
| 城市废墟 | 卡口 · 自爆 · 重甲 | 移动 ×1.0 / 掩体 0.8 / 可引爆物 2 |
| 原始丛林 | 潮涌 · 毒区 · 突进 | 移动 ×0.9 / 毒池 ✓ / 掩体 0.35 |
| 沼泽疫地 | 迟滞 · 毒区 · 远程压制 | 移动 ×0.6 / 毒池 ✓ / 掩体 0.2 |
| 荒漠废土 | 开阔 · 远程压制 · 突进 | 移动 ×1.0 / 掩体 0.05 |
| 雪原冻土 | 迟滞 · 围猎 · 精英护盾 | 移动 ×0.7 / 掩体 0.25 |
| 军事禁区 | 重甲 · 围猎 · 分裂 | 移动 ×1.0 / 掩体 0.7 / 可引爆物 2 |

旧版的"草原"并入"原始丛林"（两者在旧版都是"无遮挡全向来敌"，
与新版"开阔"维度的职能重叠）。

**场景顺序即教学顺序**：城市废墟 → 原始丛林 → 荒漠废土 → 军事禁区 → 雪原冻土 → 沼泽疫地。
沼泽疫地排在最后是刻意的——它三个维度等权（8/8/8），没有"主维度"可以集中资源对付。

### 13.3 地形要素（未改，但职能变了）

地形要素本身沿用旧版，**改的是它在体系里的位置**：
旧版它是地图属性，新版它是某个维度的表达手段。

| 地形元素 | 机制 | 现在服务于哪个维度 |
|---|---|---|
| 建筑 / 走廊 | 绝对阻挡，视线与移动均不可通过 | **卡口** |
| 开阔地 | 无掩体，四面来敌 | **开阔** |
| 沼泽 / 水域 | 减速（全场景修正） | **迟滞** |
| 冰面 | 打滑，转向/急停延迟 | **迟滞** |
| 毒洼 | 持续伤害区 | **毒区** |
| 可破坏障碍 / 油桶 | 破坏后开通路径，也会放出僵尸 | **自爆** |

**只有 6 种地形要素，但要表达 12 个维度**——
所以 F1（数量与节奏）、F2（抗性与反制）两族的 6 个维度**完全靠僵尸构筑**，
不靠地形。这个分工是刻意的：地形维度改变"你能站在哪"，
僵尸维度改变"你要打什么"。两者交替出现，玩家才会同时调整站位和阵容。

### 13.4 地图尺寸与视线

地图尺寸 **256×256 格**，视口约 25 格半径。

**"水域仅特定角色可通行"这条旧设计仍然成立**，但它在体系里的价值变了：
旧版它是"阵容决定能走哪条路"的地图决策，
新版它是**迟滞维度的一种解法**——绕开还是硬穿，取决于你带没带对的人。
