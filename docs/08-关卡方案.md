# 08 关卡方案

> 世界地图 → 6 个场景 → 每场景 13-15 个子关卡，合计 **82 关**。
> 全部关卡由 `src/data/scenes.ts` 的 `expandScene()` 推导，本文所有数字都是它的输出，
> 不手填。想看某一关长什么样，读 `expandScene()` 的结果，不要翻表。
>
> 本文是设计顺序倒置的产物：**先定挑战维度，再设计角色**。
> 所以这里不引用任何角色数据，角色是"对着这张表"设计出来的（见 `09-角色与成长.md`）。

---

## 1. 长期成长线：从"一局 15 分钟"到"一张地图 82 关"

旧版把整个游戏压成一局：15 分钟，3 个阶段，3 个 BOSS，打完回到主菜单。
那是一个**单局体验**，不是一条成长线——玩家第二次打开游戏，面对的是同一局。

新版是四层结构：

```
世界地图
  └─ 6 个场景（各自一个挑战签名）
       └─ 每场景 13-15 个子关卡（沿维度逐层加深）
            └─ 每个子关卡 = 一次 15 分钟单局（C1：时长不变）
                 └─ 三档难度（C4：同一关可以打三遍，且三遍不一样）
```

**玩家的长期循环**：

```
解锁新关卡 → 撞上新的维度 → 现有阵容解不掉
           → 解锁/强化特定角色 → 重组阵容 → 通关 → 下一关
```

关键在第三步：**卡住玩家的必须是一个"种类"问题，不是一个"数字"问题。**
"我的输出不够"会让玩家去刷数值；"我没有人能解这个维度"才会让玩家去换阵容。
所以每个新维度引入时，前面几关都设计成"用老阵容能过，但明显吃力"。

## 2. 挑战维度的定义与判据

### 2.1 什么叫"维度"

**维度 = 压力的来源，不是数值的档位。**

一条判据决定了一个压力源够不够格当维度，两条缺一不可：

1. **破解它需要特定种类的能力，而不是更高的数字。**
   如果"把攻击力翻倍"就能解，它是数值，不是维度。
2. **至少有 3 个不同定位的角色能回答它。**
   达不到说明这个维度只有一个阵容能解——那"多套阵容"就只是文案。

第 2 条由哨兵 §9 机械校验，不是靠自觉（见 `09-角色与成长.md` §4）。

### 2.2 12 个维度（4 族 × 3）

族的划分有意义：**同族内的维度要求同类能力，跨族才要求完全不同的能力。**
所以"阵容是否偏科"可以看它在四族上各答了几个。

| 族 | 维度 | 战场上是什么感觉 | 破解需要什么种类的能力 |
|---|---|---|---|
| **F1 数量与节奏** | **潮涌** | 一眼望不到边的小僵尸，单个不疼，但你只有 5 个人 | 范围清场：一次攻击覆盖多个目标 |
| | **突进** | 跑得比你快的僵尸，从你反应不过来的时候就已经贴脸了 | 控制/减速 + 近距爆发，或高攻速快速点掉 |
| | **围猎** | BOSS 或精英在正面，小怪同时从侧面压上来 | 分火能力，或一个能扛住正面让全队集火的支点 |
| **F2 抗性与反制** | **重甲** | 打上去全是白字，它们走得很慢但你拦不住 | 穿透或爆炸/火焰——靠堆攻击力没用 |
| | **分裂** | 你一发 AOE 打死了三只，场上反而多了九只 | 单体点杀，或先控住再逐个处理 |
| | **精英护盾** | 怎么打都不掉血，直到某个瞬间它突然变得很脆 | 破盾手段 + 集火窗口，AOE 磨盾是浪费 |
| **F3 地形与空间** | **卡口** | 只有一条路，僵尸排队进来，你的五个人挤在一起 | 直线穿透或堵口能力，把走廊变成绞肉机 |
| | **开阔** | 没有墙，没有掩体，四个方向同时来人 | 持续输出 + 全域索敌，或者能自己创造阵地的召唤物 |
| | **迟滞** | 脚下的地不让你好好走，走位这件事突然变得很贵 | 机动力，或者干脆不依赖走位的远程输出 |
| **F4 持续与区域** | **毒区** | 地上全是不能踩的东西，你被一点一点挤到墙角 | 续航治疗，或能在毒区外解决战斗的射程 |
| | **自爆** | 它们不咬你，它们只是走过来然后炸掉 | 远程点杀或击退，把爆炸挡在接触距离之外 |
| | **远程压制** | 站着不动就一直在挨打，可前面又有一堆东西挡路 | 主动前压的突进手段，或者比它更长的射程 |

### 2.3 维度靠"地形 × 僵尸"构筑（不是靠数值）

这是用户明确要求的一条。每个维度声明两样东西：

- **地形要素**：这个维度在关卡里靠什么地形被表达出来
- **僵尸池**：哪些僵尸贡献这个维度

刷怪表由两者加权推导，**不存在"手写 82 张刷怪表"这件事**（见 §5）。

| 维度 | 地形要素 | 僵尸池 |
|---|---|---|
| 潮涌 | — （纯靠数量） | 普通僵尸 · 分裂小僵尸 |
| 突进 | — | 高速僵尸 |
| 围猎 | — | 护盾僵尸 · 喷吐僵尸 |
| 重甲 | — | 高防胖僵尸 |
| 分裂 | — | 分裂僵尸 · 分裂小僵尸 |
| 精英护盾 | — | 护盾僵尸 |
| 卡口 | 建筑 · 走廊 | 高防胖僵尸 · 毒液僵尸 |
| 开阔 | 开阔地 | 高速僵尸 · 跳跃僵尸 |
| 迟滞 | 沼泽 · 水域 · 冰面 | 跳跃僵尸 |
| 毒区 | 毒洼 · 沼泽 | 毒液僵尸 |
| 自爆 | 可引爆物 | 爆炸僵尸 |
| 远程压制 | — | 喷吐僵尸 |

**F3 三个维度全部靠地形，F1/F2/F4 大部分靠僵尸**——这个分布是刻意的。
地形维度改变的是"你能站在哪"，僵尸维度改变的是"你要打什么"。
两者交替出现，玩家才会同时调整站位和阵容，而不是只调其中一个。

### 2.4 与旧版僵尸表的对应（7 → 9 种）

新增 2 只，专门服务两个新维度：

| 僵尸 | 血 | 速 | 甲 | 行为动词 | 贡献维度 |
|---|---|---|---|---|---|
| **护盾僵尸** | 900 | 1.8 | 中甲 | **破防检查** | 精英护盾 · 围猎 |
| **喷吐僵尸** | 600 | 1.6 | 轻甲 | **远程压制** | 远程压制 · 围猎 |

护盾僵尸正面护盾吸收固定伤害，破盾后 3 秒虚弱（受伤 +50%），**不吃控制**——
它逼迫阵容准备"爆发窗口"这个能力，而不是"更多的持续输出"。
喷吐僵尸在 12 格外远程喷吐，不进入接触距离——它让"龟缩阵地"这个稳赢打法第一次付出代价。

原有的 7 种各补一个 `dims` 字段声明自己贡献哪些维度，数值未改动。

## 3. 六个场景

场景名沿用 `05-资产清单.md` §5 已预算过资产的 6 个地形，但**含义全变了**：
旧版是"6 张地形不同、机制微调的地图"，新版是"6 个要什么阵容各不相同的挑战签名"。
旧版"草原"并入"原始丛林"。

| 场景 | 签名维度 | 地形修正 | 一句话 |
|---|---|---|---|
| **城市废墟** | 卡口 · 自爆 · 重甲 | 移动 ×1.0 / 掩体 0.8 / 可引爆物 2 | 街道被楼体切成走廊，爆炸僵尸从拐角后面走出来，胖僵尸堵住唯一的出口 |
| **原始丛林** | 潮涌 · 毒区 · 突进 | 移动 ×0.9 / 毒池 ✓ / 掩体 0.35 | 树冠遮住视线，小僵尸像潮水一样从灌木里渗出来，毒液僵尸死在你退无可退的地方 |
| **沼泽疫地** | 迟滞 · 毒区 · 远程压制 | 移动 ×0.6 / 毒池 ✓ / 掩体 0.2 | 每走一步都在往下陷，喷吐僵尸站在你够不到的地方慢慢磨 |
| **荒漠废土** | 开阔 · 远程压制 · 突进 | 移动 ×1.0 / 掩体 0.05 | 没有一处掩体，四个方向同时来人，跑得最快的和最远的同时在打你 |
| **雪原冻土** | 迟滞 · 围猎 · 精英护盾 | 移动 ×0.7 / 掩体 0.25 | 冰面上刹不住脚，精英护盾僵尸顶在最前面，小怪趁你打不动它的时候围上来 |
| **军事禁区** | 重甲 · 围猎 · 分裂 | 移动 ×1.0 / 掩体 0.7 / 可引爆物 2 | 装甲单位推进得又稳又慢，精英在正面吸引火力，分裂僵尸逼你不能用范围武器 |

**沼泽疫地的 `moveMul: 0.6` 是全游戏最强的一条地形修正**，
所以它的签名维度里有两个都在惩罚"原地不动"（迟滞、远程压制）——
地形不让你走，僵尸又逼你走，这个矛盾就是它的挑战。

### 3.1 场景顺序即教学顺序

六个场景不是并列的，有推荐推进顺序，理由是**维度难度的递进**：

```
城市废墟  卡口/自爆/重甲   三维都靠"站位纪律"和"点名"，最容易读懂
原始丛林  潮涌/毒区/突进   第一次要求"清场速率"这个能力
荒漠废土  开阔/远程压制/突进  第一次要求"主动进攻"而不是占住地形
军事禁区  重甲/围猎/分裂   第一次要求"反制"——你的清场武器会变成负担
雪原冻土  迟滞/围猎/精英护盾 第一次要求"爆发窗口调度"
沼泽疫地  迟滞/毒区/远程压制 三个维度互相加固，没有短板可以牺牲
```

**沼泽疫地排在最后是刻意的**：它的三维等权（8/8/8），没有"主维度"可以集中资源对付。
前面每个场景的终关都还留着一个主次结构，玩家可以取舍；沼泽疫地的终关不给这个选项。

## 4. 阶梯：子关卡怎么推导出来

每个场景定义一条 `ladder`：5 段，每段声明关数、活跃维度与权重、威胁增长率。
**不是手写 13-15 行表，而是从这 5 段展开。**

```
段 1  引入期   3 关   单维度，纯教学      "教会玩家这个维度是什么感觉"
段 2  叠加期   3 关   主维度 + 次维度      "加入第二个维度，形成第一个两难"
段 3  叠加期   3-4 关 三维全开，主次分明   "第三个维度进场，开始需要取舍"
段 4  组合期   3-5 关 权重最深的区间       "本场景的标准解区间"
段 5  终关     1 关   权重重新集中到主维度 "BOSS 与维度群同时压上"
```

**关数为什么是 13 或 15**：城市废墟与原始丛林的第 4 段是 4-5 关，其余四个是 3 关。
这不是疏漏——前两个场景是**教学场景**，标准解区间留得更长，
让玩家有足够空间试出"我该带谁"。第 4 段之后场景就直接进终关了。

### 4.1 威胁预算只做温和增长

同场景内，威胁预算从 3.0 涨到 6.16（原始丛林 15 关），**只有 ×2.05**。
而活跃维度从 1 个变成 3 个且权重全开。

这是"不堆数值"在数值层的具体实现：**难度增长主要来自构成，不是来自预算。**
如果玩家在丛林-15 卡住，他需要的是"换一个能同时解潮涌+毒区+突进的阵容"，
而不是"回去把武器再练高点"。（武器也没有局外养成，见 `00-决策清单.md` C3。）

- **刷怪表是推导出来的，不是配置的。** 毒液僵尸贡献「毒区」和「卡口」两个维度，

- **第 3 关到第 4 关是这道场景最重要的一次跳变**：刷怪表从"只有普通僵尸"

- **终关（jungle-15）把权重重新压回潮涌 10。**
  场景最后 5 关一直在加毒区和突进的权重，让玩家以为答案是"抗消耗"；
  终关突然把潮涌权重顶格，把答案拉回"你的清场速率够不够"。
  这是阶梯的"收束"——终关是**对整条阶梯主线的回扣**，不是维度的简单叠加。

### 5.1 完整关名与 BOSS 分派

关卡名由场景名 + 序号 + 段标签生成（`丛林 07 · 毒雾带`），不单独维护文案。

BOSS 从全局池 `BOSSES` 里按场景自己的 `bossStages` 三元组取，
按关卡进度分派（第 1-5 关取第一个，6-10 关取第二个，11 关以后取第三个）。
**所以同一个 BOSS 在不同场景里的登场时机不同**——丛林终关是卡俄斯，
沼泽终关是腐化重装兵（`bossStages: [1, 2, 0]`）。同一个 BOSS 换到不同的维度组合里，
打法完全不同，这是复用 BOSS 资产但不复用体验的做法。

| 场景 | bossStages | 终关 BOSS |
|---|---|---|
| 城市废墟 | [0, 1, 2] | 尸潮之主·卡俄斯 |
| 原始丛林 | [0, 1, 2] | 尸潮之主·卡俄斯 |
| 沼泽疫地 | [1, 2, 0] | 腐化重装兵 |
| 荒漠废土 | [0, 2, 1] | 毒母·薇丝 |

## 6. 三档难度（C4）

**难度档刻意不是"同一条曲线乘系数"。** 三档改的是**构成**：

| 档 | 威胁预算 | 权重上移 | 引入期 | 环境修正 |
|---|---|---|---|---|
| **普通** | ×1.0 | 0 档 | 标准 | 无 |
| **困难** | ×1.25 | 1 档（次级维度权重上抬） | 标准 | 无 |
| **噩梦** | ×1.5 | 2 档 | **下一段维度提前半权重进场** | 毒池不消失 / 无补给箱 / BOSS 提前 60 秒（按场景取其一） |

### 6.1 权重上移是什么意思

`shiftWeights()` 把**非最高权重**的维度整体抬升，缩小主次差距：

```
困难档：潮涌 10 保持，毒区 4 → 5.2，突进 4 → 5.2
噩梦档：潮涌 10，毒区 4 → 6（再叠一层权重上移）
```

于是**同一个关卡在三档下是不同的战场**，而不是同一场战斗里更肉的同一种僵尸。
困难档要处理的"配角维度"更多，噩梦档则几乎把三维拉平——
原本"集中资源解主维度、次要维度靠抗性硬吃"的策略在噩梦档失效。

### 6.2 噩梦档的引入期压缩：为什么是"提前引入"而不是"删关卡"

初版噩梦档的实现是**删掉前两段的关卡各一关**，让玩家更快进入三维区间。
这个做法有一个致命副作用：**同一个关卡 id 在不同难度下指向不同内容。**

```
普通档 jungle-13 = 深林（第 4 段中段）
噩梦档 jungle-13 = 母巢（终关）
```

同名不同关。存档、进度、"我卡在丛林-13"这句话、玩家之间的交流，全部失准。
关数也从 15 变成 13，地图完成度显示成 13/15 还是 13/13 说不清。

**所以改成"提前引入"**：噩梦档把**下一段的维度按半权重提前放进当前段**，
关数不变（82 关三档一致）。

```
普通檔 jungle-01  潮涌 10                     单一维度，平稳开场
噩梦档 jungle-01  潮涌 10 · 毒区 5.2          第 1 关就两个维度，没有平稳开场
```

压缩引入期的效果达成了（噩梦档玩家第一关就要同时处理两件事），
但关卡标识保持唯一。**代价是噩梦档的第 1 关不再是教学关**——这正是它该有的样子。

## 7. 维度覆盖与"多套阵容"的可验证性

### 7.1 哨兵 §9：覆盖矩阵

每个维度至少要 **3 个答案形状**、来自 **≥2 个不同定位**。
答案的详细定义与赋值见 `09-角色与成长.md` §4。

当前 12 个维度**全部达标**，且没有一个答案标签是无人使用的死标签。

### 7.2 哨兵 §10：阵容枚举——**这一条要诚实地读**

哨兵枚举了全部 C(12,5) = 792 套阵容，对每一关数"有多少套阵容能覆盖该关的全部活跃维度"。

实测结果（`npm run sim` §10 直接输出，不手抄）：

```
阵容总数                                792
能覆盖全部 12 个维度的阵容              693 套（占 87.5%）
全 82 关里门槛最高的一关                736 套可行（占 92.9%）
```

而且 **82 关里有 38 关并列这个门槛**，按维度构成归并只有 7 组：

| 维度构成 | 关数 | 属于 |
|---|---|---|
| swarm+poison | 3 | 原始丛林 |
| swarm+poison+rush | 9 | 原始丛林 |
| sluggish | 6 | 沼泽疫地 + 雪原冻土 |
| sluggish+suppress | 3 | 沼泽疫地 |
| sluggish+suppress+poison | 7 | 沼泽疫地 |
| sluggish+shielded | 3 | 雪原冻土 |
| sluggish+shielded+eliteHunt | 7 | 雪原冻土 |

**这个并列本身就是结论**：门槛由「最稀有的那个维度」单方面决定，跟关卡序号、
跟"凑了几个维度"都无关。含 `sluggish` 或 `poison` 的关卡，不管另外两个维度是什么，
可行阵容数都是 736。

**这个数字说明的事情比它听起来弱得多，不要误读。**

覆盖门槛几乎不筛人：最紧的一关也放行 92.9% 的阵容。原因是结构性的——
5 名队员、每人平均能回答 **7.4 个**维度（这个数哨兵里也是算出来的），并集自然铺满全集。
所以**"能不能进"这件事基本是免费的，二分覆盖数不能证明"阵容选择有后果"。**

它仍然有价值的唯一理由在 §9：每个维度都至少有 3 种答案形状、2 个不同定位可回答，
即**不存在"没有任何角色能应付的维度"**。这是可玩性下限，不是深度证明。

**真正决定阵容区分度的，是同一维度下不同答案的效率差。**
比如用穿透枪阵解潮涌，和用范围清场解潮涌，清怪速率差多少？
这需要把维度折进刷怪与承伤模型里才量得出来，当前模拟器结构上做不到
（见 `02-数值表.md` §10）。

**所以本轮不声称"阵容已经有多样性"，只声称"维度没有死胡同"。**
用户要求的"每种挑战不止有单一方案"这一条，目前只完成了下限，
上限要等 M2 原型才能量。

### 7.3 稀有维度是唯一的过滤器

上表的门槛全部由两个维度决定：**迟滞**和**毒区**（各 3 个答案、4 个定位），
它们各自把 792 套阵容筛到 736 套——**别的维度在覆盖上几乎是免费的。**

而且这两个维度是**同一批人**在回答：

```
迟滞 = 毒区 = { 罗恩, 凯, 薇拉, 莉安 }
```

（迟滞的答案是续航/机动/射程，毒区的答案是续航/射程/机动/减伤，落在同一组角色上。）
所以"2 个检查点"实际是**同一个检查点数了两遍**。

这对教学是好消息：玩家的实际体验会是"在沼泽疫地第 1 关就发现队里没人能在泥里跑"，
而不是打到第 10 关才发现。**问题暴露得早，改阵容的成本低。**

但它也暴露了一个真问题：**如果只有一个检查点，那"多套阵容"就从
12 个维度退化成了 1 条约束。** 这是本轮设计的下限所在，
需要在 M2 里用效率差（而非覆盖数）重新量。
