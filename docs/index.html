跑数值哨兵

所有数值表的真源是 src/data/*.ts，输出由模拟器生成。文档里的数字全部从模拟器导出，不手填。

npm run sim          # = node src/sim/balance-check.ts

Node 24 原生支持 TypeScript 类型剥离，不需要 tsx / ts-node。输出八节实测表：角色属性预算 / 单角色基准 / BOSS DPS 锚点 / BOSS 血量反向校准 / 生存压力 / 15 分钟全程模拟 / 承伤现实检查 / 多阵容鲁棒性。

改数字去 src/data/；改图表去 src/sim/balance-check.ts，重跑，再把输出同步进 02-数值表.md。

这套模拟器能证明什么，不能证明什么

能：清怪速率够不够、BOSS 血量锚点对不对、阵容之间有没有区分度、各乘区有没有写错。 结论是配平自洽。

不能：会不会死人、难度手感对不对、走位有没有意义。 三个简化叠起来抹掉了整个生存维度——地图抽象成一维距离、索敌是单点最近目标、队员完全不走位。 实测常规阶段僵尸贴身占比 0%，140 次运行 0 阵亡。

难度必须靠真人原型试玩验证。详见 02-数值表 §10。
